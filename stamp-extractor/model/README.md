# Модель `models/ink-seg.onnx`

Небольшая свёрточная сеть (U-Net из depthwise-separable блоков, 114 581 параметр,
файл ≈ 0,46 МБ). Для каждой точки документа она независимо оценивает
вероятность пяти классов: печатный текст, линия бланка или таблицы, рукописный
текст, подпись, печать. Несколько классов могут быть высокими одновременно: так
размечены пересечения, например печать поверх подписи. Выход сети имеет половинное
разрешение рабочего изображения (длинная сторона не больше 1600 пикселей).

## Данные

Сеть обучена **только на синтетических документах** из `synth.py`. Реальные сканы
и чужие наборы данных для обучения не использовались. Генератор рисует:

- печатный текст: русский, белорусский и английский словарь, системные шрифты
  DejaVu, Liberation, FreeFont, Carlito; абзацы, таблицы, подписи полей,
  штрихкоды и QR-подобные блоки;
- линии бланка и подчёркивания;
- рукописные записи шрифтами Google Fonts (SIL OFL, `fetch_fonts.py`) с упругими
  искажениями, наклоном и неравномерностью чернил шариковой ручки;
- подписи: росчерки из кривых Катмулла — Рома с переменным нажимом или фамилии
  рукописными шрифтами, петли и подчёркивания;
- печати: круглые с текстом по дуге, внутренними кольцами, гербовыми фигурами
  и номерами; прямоугольные штампы; овальные и треугольные; синие, фиолетовые,
  красные, чёрные; неравномерный оттиск, выпадения краски, двойной оттиск,
  частичный оттиск. Названия организаций вымышленные.

Слои накладываются умножением, как чернила. Затем применяются искажения сканера,
фотографии (перспектива, неравномерный свет, оттенок), оттенки серого,
чёрно-белая бинаризация, потеря резкости и JPEG-сжатие.

## Как обучена поставляемая модель

Обучение выполнялось на 4 ядрах CPU без видеокарты: батч 12 фрагментов 256×256,
AdamW, расписание OneCycle, функция потерь BCE + Dice. Из-за перезапуска среды
и доработки генератора обучение прошло в три фазы:

| Фаза | Данные | Шаги | Начальная точка | Макс. LR |
| --- | --- | ---: | --- | ---: |
| 1 | 3200 страниц, сиды 1000–4199, генератор из коммита `WIP: Stamp extractor 4.0…` | 2000 (расписание на 7000 прервано) | случайная инициализация | 3e-3 |
| 2 | тот же набор | 1250 (расписание на 5000 прервано) | конец фазы 1 | 2e-3 |
| 3 | 3200 страниц, сиды 20000–23199, текущий `synth.py` | 4000 | конец фазы 2 | 1,5e-3 |

Между фазами 2 и 3 генератор доработан. Добавлены крупные многострочные
прямоугольные штампы с должностями и фамилиями и чёткие «цифровые» оттиски без
текстуры краски (25 % печатей). Доля прямоугольных штампов увеличена.

## Воспроизведение

```bash
python3 -m venv .venv && .venv/bin/pip install -r model/requirements.txt
.venv/bin/python model/fetch_fonts.py
cd model
../.venv/bin/python train.py generate --out ../build/dataset --count 3200 --seed 20000
../.venv/bin/python train.py train --data ../build/dataset --steps 4000 --lr 1.5e-3 --resume <контрольная точка фаз 1–2> --out ../build/ink.pt
../.venv/bin/python train.py export --checkpoint ../build/ink.pt --out ../models/ink-seg.onnx
```

Для обучения с нуля одной фазой: `train.py train --data ../build/dataset --steps 7000`.
Получится модель, близкая к поставляемой, но не идентичная ей. Генерация и
порядок батчей используют фиксированные сиды. Побитовое совпадение весов на
другом железе или с другими версиями PyTorch не гарантируется.

## Ограничения

Синтетические данные не покрывают всё разнообразие реальных документов.
Особенно трудны настоящие подписи, не похожие на сгенерированные росчерки;
печати с нетипичной графикой; сильно размытые фотографии; одноцветные пересечения.
Результаты измерений и их условия: `../VALIDATION.md`.
