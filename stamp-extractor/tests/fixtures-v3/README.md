# Регрессии по обнаруженным ошибкам

Это **авторские воспроизведения компоновки**, а не загруженные пользователем
картинки и не результаты обработки его документов. Генератор:
`python3 tests/generate-failures.py`; зависимости — Pillow, NumPy, системные
DejaVu Sans / DejaVu Serif. Все имена организаций и фамилии условные.

| Пример в `../../examples/` | Проверяемая ошибка | Ожидаемые объекты |
| --- | --- | --- |
| `failures-rectangular.png` | Две наклонные прямоугольные печати; собственные буквы печатей; подписи и длинные рукописные строки того же синего цвета, пересекающие рамки | 2 печати, 2 подписи |
| `failures-rectangular-clean.png` | Контроль сохранности текста и рамки тех же печатей без рукописного наложения | 2 печати |
| `failures-form-signature.png` | Размашистая синяя подпись, пересеченная черными линиями бланка и напечатанными подписями полей | 1 подпись |
| `failures-text-only.png` | Разрозненные короткие печатные слова, инициалы, цифры и фрагмент `ости.,` черным цветом | 0 |
| `failures-text-only-blue.png` | Те же печатные фрагменты синим цветом | 0 |

В JSON для каждого изображения есть размеры, `objects`, `backgrounds` и
`printed_words`. Координаты слов получены из отрисовки, **не из OCR**;
`role: "stamp"` указывает на собственные надписи печати для анализа качества,
но не является подсказкой, доступной алгоритму при реальном использовании.
У слов также есть `symbols` с известными координатами отдельных печатных букв.
При интеграционных проверках необходимо отдельно прогонять настоящий OCR.

Маски — grayscale PNG полного размера исходного документа, 0 означает фон,
255 — чернила, промежуточные значения — сглаживание. Для измерений используется
порог > 32. Отдельно сохранены рамки, буквы печатей, подписи, печатный текст,
линии бланка и нежелательные рукописные строки.

`*.mask.png` содержит полную исходную фигуру, известную только генератору.
`*.visible.mask.png` исключает чернила, закрытые позднее нарисованными слоями.
`*.expected.png` — чистый эталон фигуры, а **не обещание** восстановить скрытые
штрихи из конечного скана. При одинаковом цвете перекрывающихся штрихов их
принадлежность одному из слоев нельзя однозначно определить по изображению.
Достройка скрытых фрагментов должна оцениваться отдельно от извлечения.

Диагностический отчет с текущим алгоритмом:
`node tests/fixtures-v3/evaluate.mjs`. Он записывает извлеченные изображения и
JSON с числом объектов, сохранностью видимых штрихов/букв и остатками фона в
`test-results/failures-v3/known-words/`. Вариант с настоящим встроенным OCR:
`node tests/fixtures-v3/evaluate.mjs --ocr`; результат сохраняется отдельно в
`test-results/failures-v3/ocr/`. Это измерение, а не утверждение, что все случаи
успешно обработаны. Отчет не заменяет тестирование на исходных фотографиях.

Генератор и растровые тестовые данные распространяются по MIT проекта.
Шрифты в репозиторий не включены; используются системные DejaVu, разрешающие
создание и распространение полученных растровых изображений.
