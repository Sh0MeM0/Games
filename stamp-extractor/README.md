# Печати и подписи 2.0

Portable-программа для Windows 10/11 x64: открывает скриншот, скан или фотографию,
распознаёт печатный текст, выделяет печати и подписи и сохраняет каждый найденный
объект отдельным PNG на чистом белом непрозрачном фоне. Обработка полностью локальная.

## Скачать

[**StampExtractor-Portable-2.0.0.exe**](https://github.com/Sh0MeM0/Games/blob/stamp-extractor/downloads/StampExtractor-Portable-2.0.0.exe)

На странице GitHub нажмите **Download raw file**. Нужен именно `.exe`, а не ZIP
исходников: большие файлы хранятся в Git LFS. Контрольная сумма находится в
`downloads/SHA256SUMS.txt` в корне репозитория.

Запустите скачанный файл. Устанавливать Python, OCR, Office или дополнительные модели
не нужно; русский и английский распознаватель уже включены. Интернет и права
администратора для работы не нужны. Portable-файл распаковывается в TEMP; оставьте
около 1 ГБ свободного места. Подписи Authenticode у сборки нет.

## Как пользоваться

1. Откройте PNG, JPG/JPEG, WEBP или BMP либо перетащите изображение в окно.
   Распознавание и выделение объектов начинаются автоматически.
2. В списке справа появятся отдельные печати и подписи. Выберите объект:
   предпросмотр показывает результат очистки, кнопка **Показать оригинал** — источник.
3. Нажмите **Сохранить все PNG**, выберите папку. Получатся отдельные файлы
   `имя_документа_печать_01.png`, `имя_документа_подпись_03.png` и т. п.
   Кнопка **Сохранить этот PNG** сохраняет только выбранный объект.

Удаление распознанного текста и линий бланка включено по умолчанию. У печати
сохраняются её собственные надписи. Синие/красные чернила отделяются от чёрного
текста; для монохромного изображения используются OCR и форма связанных штрихов.
Результат обрезается по оставшимся штрихам и получает белые поля 16 пикселей.
Оригинал не меняется, существующие PNG не перезаписываются.

Если автоматическая обработка ошиблась, смените **Тип объекта** или цвет чернил,
уменьшите удаление фона/шума для слабых штрихов. Галочки удаления текста и линий
можно выключить для выбранного объекта. Кисти **Убрать / Вернуть** и отмена/повтор
позволяют поправить маску; «Вернуть» использует только реальные пиксели источника.
Пропущенный объект можно обвести кнопкой **Выделить вручную**, лишнюю рамку — удалить
крестиком. **Повторить поиск** сбрасывает ручные изменения рамок. Цветовой фильтр
слева действует на следующий поиск.

## Что изменилось относительно 1.0

В 1.0 текст вообще не распознавался: поиск объединял соседние штрихи. В 2.0
добавлены встроенный Tesseract OCR с русской и английской моделями, удаление
распознанного печатного текста, защита надписей внутри обнаруженных печатей,
выделение связных рукописных штрихов, раздельная обработка цветов и удаление длинных
линий бланка. Проверки используют документы с абзацами, надписями в печатях и
несколькими подписями, а не только отдельные фигуры.

## Границы автоматической обработки

Это OCR плюс анализ геометрии и цвета, а не обученная модель всех возможных
печатей и подписей. Результат нужно просмотреть перед сохранением:

- Если подпись и печать касаются или перекрываются одинаковыми чернилами,
  автоматическое разделение может ошибиться. Текст того же цвета внутри печати
  может сохраниться вместе с её собственными буквами. Точно восстановить скрытые
  штрихи из одного изображения нельзя; используйте отдельный оттиск/исходник
  или поправьте видимые фрагменты вручную.
- Слабая/разорванная рамка, логотип без рамки, необычная подпись или текст,
  не прочитанный OCR, могут потребовать ручного выделения. Поддерживаются русский
  и английский печатный текст. Крупные декоративные надписи могут дать ложные рамки.
- Убираются плавные тени бумаги, слабый фон и мелкий шум; контраст усиливает
  существующие штрихи. Масштаб 2×/3× увеличивает изображение, но не восстанавливает
  потерянные детали. Сильное размытие и перспектива автоматически не исправляются.
- PDF, TIFF, HEIC и многостраничные документы напрямую не открываются:
  сохраните нужную страницу в PNG/JPG. Один документ за раз; до 80 объектов,
  входной файл до 80 МБ. Изображения больше 24 Мп или 16000 пикселей по стороне
  уменьшаются; экспорт ограничен 32 Мп и 100 МБ на PNG.
- Проект с рамками не сохраняется между запусками. После аварийного завершения
  временная папка приложения может остаться в TEMP.

## Разработка и сборка

Из каталога `stamp-extractor`, Node.js 24:

```bash
npm ci
npm test
npm run test:ui
npm run test:documents
npm start
npm run dist:win
```

Результат: `release/StampExtractor-Portable-2.0.0.exe` — один portable-файл.
OCR-модели хранятся в `resources/ocr`; повторная загрузка с проверкой SHA-256:
`npm run models:fetch` (Python 3 нужен только разработчику для этой команды).
Источник, закреплённая версия и лицензия моделей: `resources/ocr/README.md`.

Linux-сборка Windows portable без Wine:

```bash
npm run dist:win -- --config.win.signAndEditExecutable=false
```

`test:ui` и `test:documents` запускают настоящий Electron, OCR, worker и экспорт
на диск; автоматизируется лишь выбор папки. На Linux используется Ozone headless
и `--no-sandbox` в изолированной тестовой среде; этот флаг не входит в приложение.
Фактически выполненные проверки и ограничения проверки Windows — в [VALIDATION.md](VALIDATION.md).

Код приложения: MIT. Tesseract.js и модели: Apache-2.0; лицензии и модели включены
в сборку. Electron/Chromium/Node распространяются со своими лицензиями. Примеры
созданы программно: это вымышленные учебные документы, не подписи реальных людей.
