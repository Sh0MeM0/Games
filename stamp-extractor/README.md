# Печати и подписи

Локальная portable-программа для Windows 10/11 x64. Открывает скриншоты,
сканы и фотографии в PNG, JPG/JPEG, WEBP, BMP; предлагает отдельные области,
очищает фон и сохраняет каждый объект отдельным непрозрачным PNG на белом фоне.
Установка, Python, Office, аккаунт и интернет для обработки не нужны.

## Скачать и запустить

[StampExtractor-Portable-1.0.0.exe](https://github.com/Sh0MeM0/Games/blob/stamp-extractor/downloads/StampExtractor-Portable-1.0.0.exe)
— на странице файла нажмите **Download raw file**. Это Git LFS-файл; ZIP
исходников может содержать указатель вместо самого `.exe`.
Контрольная сумма: `downloads/SHA256SUMS.txt`.

Запустите `.exe` из любой доступной папки, например с флешки.
Portable launcher распаковывает приложение во временную папку и запускает его;
установщик, запись в список установленных программ и права администратора не нужны.
На диске для временной распаковки нужен запас около 700 МБ.

## Использование

1. Нажмите **Открыть изображение** или перетащите файл в окно.
2. Нажмите **Найти области**. Фильтр «Все чернила» включает тёмные подписи;
   «Только цветные» уменьшает количество рамок вокруг обычного чёрного текста.
3. Проверьте рамки. Лишние удаляются крестиком. Для пропущенного объекта
   нажмите **Выделить вручную** и протяните рамку вокруг одного объекта.
   Если объединены две подписи, удалите общую рамку и нарисуйте две отдельные.
   Ползунок **Объединение** влияет только на следующий автопоиск.
4. Выберите объект. Укажите цвет чернил, удаление фона, шум и контраст.
   Если пропадают тонкие штрихи, уменьшите удаление фона и мелкого шума.
5. На правом предпросмотре кистью **Убрать** сотрите ненужные линии/текст.
   Кисть **Вернуть** восстанавливает существующие слабые/удалённые штрихи.
   **↶ / ↷** и **Ctrl+Z / Ctrl+Shift+Z** отменяют и повторяют движения кисти.
   **Показать оригинал** позволяет сравнить область с источником.
6. Нажмите **Сохранить все PNG** и выберите папку. Каждая рамка создаёт свой
   файл; возможен экспорт только выбранной рамки. Совпадающие имена получают
   суффикс, существующие файлы не перезаписываются. Папка открывается кнопкой внизу.

У каждого объекта свои настройки, имя и ручная очистка. **Дублировать** создаёт
вторую рамку в том же месте: удобно отдельно попробовать синие и тёмные чернила.
Готовые PNG обрезаются по оставшимся штрихам и получают белые поля 16 пикселей;
масштаб 2×/3× увеличивает размеры вместе с полями, сохраняя непрозрачность.

## Что программа делает и чего ожидать

- Автопоиск — анализ цвета и связанных штрихов, а не нейросетевое распознавание
  личности или юридического типа объекта. Обычный текст тоже может стать областью.
- Подписи/печати, расположенные раздельно, можно сохранить отдельными файлами.
  При касании или пересечении алгоритм может объединить их: используйте ручные рамки,
  фильтр цвета и кисти. Если штрихи одинакового цвета пересекаются, достоверно
  восстановить скрытое по одному изображению невозможно. Программа не дорисовывает
  отсутствующие детали. Практичная альтернатива — исходный документ или отдельный скан.
- Очистка удаляет плавный светлый/серый фон, слабый шум и мелкие отдельные точки,
  усиливает существующие штрихи. Текст внутри одноцветной печати автоматически
  отличить от её собственных букв нельзя: нужна ручная очистка.
- Увеличение, контраст и интерполяция не возвращают детали размытой фотографии.
  Исправление сильного перспективного искажения и автоматическая деконволюция
  размытия в этой версии не реализованы. Лучше переснять лист ровно при хорошем свете.
- PDF, TIFF, HEIC и многостраничные документы напрямую не открываются:
  сохраните нужную страницу в PNG/JPG. Анимированные изображения не обрабатываются
  как набор кадров. Нет автоматического сохранения проекта с рамками между запусками.
- Один документ за раз, до 80 областей, файл до 80 МБ. Изображения больше 24 Мп
  или длиннее 16000 пикселей по стороне уменьшаются с сообщением внизу.
  Результат после увеличения — до 32 Мп и 100 МБ на PNG.

Оригиналы не изменяются; экспорт выполняется только в выбранную папку.
Обработка полностью локальная. Сетевые запросы блокируются в Electron и CSP;
телеметрии, обновлений и внешних сервисов нет. Профиль Chromium находится в TEMP;
после аварийного завершения временная папка может остаться.

## Разработка и сборка

Node.js 24, команды из `stamp-extractor`:

```bash
npm ci
npm test
npm start
npm run test:ui
npm run dist:win
```

`test:ui` использует настоящий Electron, preload, worker и экспорт на диск;
автоматизирован только выбор выходной папки. В Linux проверка запускает Electron
с Ozone headless и `--no-sandbox` в изолированной тестовой среде; portable-приложение
не содержит этот флаг. При первом запуске разработки Electron загружает платформенный
runtime. `examples/` содержит только синтетические тестовые фигуры, не реальные печати/подписи.

Linux-сборка Windows portable без Wine:

```bash
npm run dist:win -- --config.win.signAndEditExecutable=false
```

Результат: `release/StampExtractor-Portable-1.0.0.exe`. Используется поддерживаемый
portable target electron-builder, без установочного NSIS-сценария. В Linux отключается
редактирование PE-ресурсов; заголовок окна и интерфейс остаются русскими.
Подпись Authenticode не добавляется. Подробности фактических проверок — `VALIDATION.md`.

Код приложения: MIT. Electron/Chromium/Node и упаковщик распространяются со своими
лицензиями; штатные `LICENSE.electron.txt` и `LICENSES.chromium.html` включаются
в пакет electron-builder.
