# Печати и подписи 3.0

Portable-программа для Windows 10/11 x64: открывает скриншот, скан или фотографию,
распознаёт печатный текст, ищет печати и подписи и сохраняет каждый найденный
объект отдельным PNG на чистом белом непрозрачном фоне. Обработка полностью локальная.

## Скачать

[**StampExtractor-Portable-3.0.0.exe**](https://github.com/Sh0MeM0/Games/blob/stamp-extractor/downloads/StampExtractor-Portable-3.0.0.exe)

На странице GitHub нажмите **Download raw file**. Нужен именно `.exe`, а не ZIP
исходников: большие файлы хранятся в Git LFS. Контрольная сумма находится в
`downloads/SHA256SUMS.txt` в корне репозитория.

Запустите скачанный файл. Устанавливать Python, OCR, Office или дополнительные модели
не нужно; русский и английский распознаватель уже включены. Интернет и права
администратора для работы не нужны. Portable-файл распаковывается в TEMP; оставьте
около 1 ГБ свободного места. Подписи Authenticode у сборки нет.

## Как пользоваться

1. Откройте PNG, JPG/JPEG, WEBP или BMP либо перетащите изображение в окно.
   Распознавание и выделение объектов начинаются автоматически.
2. В списке справа появятся отдельные печати и подписи. Выберите объект:
   предпросмотр показывает результат очистки, кнопка **Показать оригинал** — источник.
3. Для прямоугольной печати в поле **Состав печати** выберите
   **Рамка и печатный текст**, чтобы отделить её от рукописных наложений.
   Режим **Всё внутри рамки** сохраняет также попавшие внутрь подписи и пометки.
4. При включённом **Соединять короткие разрывы** проверьте добавления кнопкой
   **Подсветить достроенные участки**. Отключите галочку, если нужен результат
   только из исходных пикселей, без предполагаемых продолжений.
5. Нажмите **Сохранить все PNG**, выберите папку. Получатся отдельные файлы
   `документ_печать_01.png`, `документ_подпись_02_достроено.png` и т. п.
   Кнопка **Сохранить этот PNG** сохраняет только выбранный объект.

Удаление печатного текста документа, линий бланка и посторонних штрихов включено
по умолчанию. Для прямоугольных печатей по умолчанию используется слой
**Рамка и печатный текст**; для остальных — **Всё внутри рамки**. Собственные
надписи печати определяются по рамке, расположению и форме печатных букв.
Это не гарантирует разделение любого рукописного наложения того же цвета.
Результат обрезается по оставшимся штрихам и получает белые поля 16 пикселей.
Оригинал не меняется, существующие PNG не перезаписываются.

Если автоматическая обработка ошиблась, смените **Тип объекта** или цвет чернил,
уменьшите удаление фона/шума для слабых штрихов. Удаление текста, линий и
посторонних штрихов можно выключить для выбранного объекта. Кисти **Убрать / Вернуть** и отмена/повтор
позволяют поправить маску; «Вернуть» использует только реальные пиксели источника.
Пропущенный объект можно обвести кнопкой **Выделить вручную**, лишнюю рамку — удалить
крестиком. **Повторить поиск** сбрасывает ручные изменения рамок. Цветовой фильтр
слева действует на следующий поиск.

## Достройка разрывов

**Соединять короткие разрывы** продолжает два согласованных по направлению
конца штриха через участок удалённой линии или текста. Большие пробелы и
неоднозначные развилки не заполняются автоматически. **Максимальный разрыв,
пикс.** ограничивает длину соединения: 4–24 пикселя, начальное значение — 18.

Достройка включена по умолчанию, но её можно отключить у каждого объекта.
Предпросмотр сообщает число добавленных пикселей с пометкой **(предположение)**.
**Подсветить достроенные участки** показывает места добавлений; служебная
подсветка в сохранённую картинку не попадает. Если добавленные пиксели остались
в экспортируемом изображении, программа добавляет к имени файла `_достроено`.
Достройка не подтверждает подлинную форму скрытой части подписи или печати.

## Что изменилось в 3.0

- Поиск наклонных прямоугольных рамок учитывает пересекающие их штрихи;
  печать с собственными буквами обрабатывается отдельно от обычного текста.
- Для прямоугольной печати появились два состава: рамка с печатным текстом
  и всё содержимое рамки. Рукопись не считается обязательной частью печати.
- Переработан отбор подписей, чтобы короткие печатные слова, инициалы и остатки
  текста не попадали в список как подписи.
- Фоновые рукописные строки отделяются до объединения штрихов подписи. Рамка
  отделяется с учётом проходящих рядом штрихов и направления её границ.
- Добавлены отключаемые короткие соединения штрихов, их подсветка и явное
  обозначение изменённых изображений суффиксом `_достроено`.

## Границы автоматической обработки

Это OCR плюс анализ геометрии и цвета, а не обученная модель всех возможных
печатей и подписей. Результат нужно просмотреть перед сохранением:

- Рукописная строка, подпись и буквы печати могут пересекаться одинаковыми
  чернилами. В таком случае автоматическое разделение не всегда однозначно:
  могут остаться чужие штрихи или исчезнуть части нужных. Достройка не решает
  эту неоднозначность. Для точного результата нужен отдельный оттиск/подпись
  без наложений либо ручная корректировка видимых фрагментов.
- Слабая/разорванная рамка, логотип без рамки, необычная подпись или текст,
  не прочитанный OCR, могут потребовать ручного выделения. Поддерживаются русский
  и английский печатный текст. Крупные декоративные надписи могут дать ложные рамки.
- Убираются плавные тени бумаги, слабый фон и мелкий шум; контраст усиливает
  существующие штрихи. Масштаб 2×/3× увеличивает изображение, но не восстанавливает
  потерянные детали. Сильное размытие и перспектива автоматически не исправляются.
- PDF, TIFF, HEIC и многостраничные документы напрямую не открываются:
  сохраните нужную страницу в PNG/JPG. Один документ за раз; до 80 объектов,
  входной файл до 80 МБ. Изображения больше 24 Мп или 16000 пикселей по стороне
  уменьшаются; экспорт ограничен 32 Мп и 100 МБ на PNG.
- Проект с рамками не сохраняется между запусками. После аварийного завершения
  временная папка приложения может остаться в TEMP.

## Разработка и сборка

Из каталога `stamp-extractor`, Node.js 24:

```bash
npm ci
npm test
npm run test:ui
npm run test:documents
npm run test:failures
npm start
npm run dist:win
```

Результат: `release/StampExtractor-Portable-3.0.0.exe` — один portable-файл.
OCR-модели хранятся в `resources/ocr`; повторная загрузка с проверкой SHA-256:
`npm run models:fetch` (Python 3 нужен только разработчику для этой команды).
Источник, закреплённая версия и лицензия моделей: `resources/ocr/README.md`.

Linux-сборка Windows portable без Wine:

```bash
npm run dist:win -- --config.win.signAndEditExecutable=false
```

`test:ui` и `test:documents` запускают настоящий Electron, OCR, worker и экспорт
на диск; автоматизируется лишь выбор папки. На Linux используется Ozone headless
и `--no-sandbox` в изолированной тестовой среде; этот флаг не входит в приложение.
Для регрессий 3.0 созданы авторские аналоги обнаруженных ошибок: наклонные
прямоугольные печати с буквами, пересекающие их рукописные строки, подпись на
линиях бланка и отдельные печатные фрагменты. Исходные файлы пользовательских
вложений не были доступны в локальной среде; аналоги не являются проверкой
обработки именно этих вложений. Генератор, точные маски и описание — в
[tests/fixtures-v3/README.md](tests/fixtures-v3/README.md). Диагностика с настоящим
встроенным OCR: `node tests/fixtures-v3/evaluate.mjs --ocr`.

Фактически выполненные проверки и ограничения проверки Windows указаны
отдельно в [VALIDATION.md](VALIDATION.md).

Код приложения: MIT. Tesseract.js и модели: Apache-2.0; лицензии и модели включены
в сборку. Electron/Chromium/Node распространяются со своими лицензиями. Примеры
созданы программно: это вымышленные учебные документы, не подписи реальных людей.
