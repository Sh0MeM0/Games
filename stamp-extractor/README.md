# Печати и подписи 4.0

Portable-программа для Windows 10/11 x64. Открывает PDF (все страницы), сканы,
фотографии и скриншоты, находит печати и подписи и сохраняет каждый объект
отдельным PNG на белом непрозрачном фоне. Печатный текст, линии бланка,
рукописные записи и другие объекты из результата убираются. Вся обработка
выполняется на компьютере пользователя, документы никуда не отправляются.

## Скачать

[**StampExtractor-Portable-x64-4.0.0.zip**](https://github.com/Sh0MeM0/Games/raw/claude/admiring-franklin-lc42l2/downloads/StampExtractor-Portable-x64-4.0.0.zip)
— распакованная portable-версия в ZIP-архиве, контрольная сумма в
[`downloads/SHA256SUMS.txt`](../downloads/SHA256SUMS.txt).

1. Распакуйте архив **целиком** в любую папку, например на рабочий стол или флешку.
2. Запустите `StampExtractor-Portable-x64\StampExtractor.exe`.
   Файл `resources.neu` должен лежать рядом с `StampExtractor.exe`.

Установка, интернет и права администратора не нужны. Программа использует
системный компонент Microsoft Edge WebView2 Runtime. По документации Microsoft
он входит в Windows 11, а на Windows 10 устанавливается обновлениями
([learn.microsoft.com](https://learn.microsoft.com/microsoft-edge/webview2/concepts/evergreen-vs-fixed-version)).
Если окно не открывается, установите WebView2 Runtime со страницы
[developer.microsoft.com/microsoft-edge/webview2](https://developer.microsoft.com/microsoft-edge/webview2/).

Подписи Authenticode у сборки нет; Windows SmartScreen может показать предупреждение.

## Как пользоваться

1. Откройте PDF или изображение (PNG, JPG, WEBP, BMP, GIF, AVIF), перетащите файл
   в окно или вставьте скриншот через Ctrl+V. Поиск начнётся автоматически.
2. В многостраничном PDF листайте страницы кнопками ◀ ▶ (или PageUp/PageDown);
   «Найти на всех страницах» обработает весь документ.
3. Синие рамки — печати, зелёные — подписи. Выберите объект в списке: справа
   показан результат очистки, «Показать оригинал» — исходная область.
4. Если объект распознан неверно, смените **Тип объекта**, двигайте
   **Порог уверенности модели** или поправьте маску кистями «Убрать/Вернуть».
   Пропущенный объект обведите кнопкой «Выделить вручную».
5. «Сохранить все PNG» сохраняет объекты всех обработанных страниц в выбранную
   папку: `документ_стр02_печать_01.png`, `документ_подпись_03.png` и т. п.
   Существующие файлы не перезаписываются.

Переключатель **Поиск: Строже / Обычно / Мягче** меняет порог при поиске:
«Мягче» находит больше слабых объектов, но чаще ошибается.
**Достраивать перекрытые участки** (по умолчанию выключено) закрашивает цветом
печати точки, где её перекрыли чужие чернила, и соединяет короткие разрывы.
Такие пиксели — предположение: они подсвечиваются кнопкой «Подсветить
достроенные участки», а к имени файла добавляется `_достроено`.

## Как это работает

1. Страница приводится к рабочему размеру (длинная сторона не больше 1600 px),
   каждая точка делится на местный цвет бумаги: так убираются тени и оттенок света.
2. Локальная модель `models/ink-seg.onnx` (≈ 0,46 МБ, 114 581 параметр)
   через ONNX Runtime Web (WebAssembly) размечает каждую точку пятью
   независимыми вероятностями: печатный текст, линия, рукописный текст,
   подпись, печать. Пересечения могут относиться к нескольким классам сразу.
3. Чернила отделяются от бумаги без модели, по оценке фона. Модель только
   классифицирует существующие штрихи и не добавляет новые.
4. Уверенные точки «печать» и «подпись» группируются в объекты. Отбрасываются
   группы, где модель видит в основном рукописный или печатный текст, а также
   мелкие «подписи» внутри печати. «Печать» без надписей (меньше 8 мелких
   отдельных знаков) считается подписью: так выглядят крупные петли росчерка.
5. При сохранении в PNG попадают исходные пиксели выбранного класса из
   исходного разрешения страницы. Остальное заменяется белым.

Модель обучена **только на синтетических документах**. Генератор, обучение и
воспроизведение описаны в [model/README.md](model/README.md).

## Измерения и ограничения

Полные условия замеров приведены в [VALIDATION.md](VALIDATION.md). Сводка:

| Набор | 3.0: печати / подписи найдено | 3.0: ложных объектов | 4.0: печати / подписи найдено | 4.0: ложных объектов |
| --- | --- | ---: | --- | ---: |
| Синтетический тест, 120 страниц (114 печатей, 158 подписей) | 49 / 87 | 633 | 80 / 92 | 55 |
| Примеры 3.0, 10 изображений (14 / 13) | 14 / 13 | 0 | 12 / 12 | 1 |
| Реальные фото подписей, 35 кадров (0 / 35) | — / 4 | 338 | — / **0** | 66 |

- Синтетический тест создан тем же генератором, на котором обучена модель, поэтому
  эти цифры для 4.0 оптимистичны. Под примеры 3.0 настраивалась старая версия.
- **На реальных фотографиях крупным планом** (размытие, цветной свет, ручка в
  кадре) новая модель не нашла ни одной подписи из 35 и принимает размытый
  текст за печати. Для таких снимков выделяйте объект вручную.
- Реальных сканов документов с печатями для проверки не было. Точность на
  ваших документах не измерена; проверяйте каждый найденный объект.
- Две вплотную стоящие печати могут объединиться в один объект. Разделите их
  кнопкой «Выделить вручную».
- Подпись и печать одного цвета, пересекающие друг друга, разделяются не всегда.
- TIFF и HEIC напрямую не открываются: сохраните их как PDF, PNG или JPG.
- Изображения больше 24 Мп уменьшаются; на одной странице до 80 объектов.

Служебный кэш WebView2 создаётся в `%APPDATA%\StampExtractor.exe`. Исходные
файлы не изменяются.

## Разработка

Требуется Node.js 22+. Из каталога `stamp-extractor`:

```bash
npm ci
npm test
npm run test:ui
npm start
npm run build
npm run test:portable
```

- `npm ci` скачивает зависимости и копирует нужные файлы ONNX Runtime Web,
  PDF.js и клиента Neutralino в `vendor/`.
- `npm test` запускает юнит-тесты, включая прогон встроенной модели.
- `npm run test:ui` запускает интерфейс в Chromium (это движок WebView2),
  открывает PNG, PDF, вставляет скриншот и сохраняет PNG.
- `npm start` поднимает локальный сервер разработки: http://127.0.0.1:8080/www/.
- `npm run build` скачивает Neutralinojs 6.10.0 с GitHub (SHA-256 закреплён),
  собирает `resources.neu` официальной утилитой `neu` и создаёт
  `dist/StampExtractor-Portable-x64/` и ZIP.
- `npm run test:portable` запускает собранный `resources.neu` настоящим
  Neutralino той же версии (Linux, режим браузера) и сохраняет PNG через его
  файловый API.

Оценка качества: `tests/eval/` (подготовка наборов, прогон, подсчёт метрик).
