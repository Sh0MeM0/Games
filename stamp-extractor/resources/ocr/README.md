# Встроенное распознавание печатного текста

Программа работает без интернета: движок Tesseract.js 7.0.0 / Tesseract.js-core
7.0.0 установлен из npm по `package-lock.json`, WebAssembly и оба языковых файла
входят в portable EXE. Модели проверяются по SHA256 при первом распознавании.
Документы не передаются на сервер; файлы моделей и кэш не скачиваются при запуске.

Модели: [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast),
коммит `87416418657359cb625c412a48b6e1d6d41c29bd`, лицензия Apache 2.0
(`LICENSE-tessdata.txt`). Это модели печатного русского и английского текста,
не модель идентификации личности по подписи и не генератор недостающих штрихов.

| Файл | SHA256 |
| --- | --- |
| eng.traineddata | `7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2` |
| rus.traineddata | `e16e5e036cce1d9ec2b00063cf8b54472625b9e14d893a169e2b0dedeb4df225` |

Повторное получение с проверкой контрольных сумм: из каталога `stamp-extractor`
выполните `python scripts/fetch-ocr-models.py`. Для этой команды нужен интернет;
готовая программа его не использует. Исходные языковые файлы также сохранены
в репозитории. Лицензии npm-зависимостей входят в `node_modules` сборки.

Tesseract распознаёт слова и возвращает реальные координаты и уверенность;
фильтрация печатного текста использует эти результаты вместе с цветом и формой
штрихов. Размытый, сильно наклонённый или перекрытый текст может не распознаться.
