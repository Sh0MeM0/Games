# Фактические проверки 15.10.2026

Выполнено в облачной Linux-среде:

- `npm ci` из package-lock.json: зависимости установлены. Node.js 24.19.0,
  Electron 44.7.0, electron-builder 26.15.3, Playwright 1.62.1.
- `npm test`: **15 тестов прошли**, пропусков нет. Проверены отдельные области,
  вложенные штрихи внутри печати, тень, яркие JPEG-подобные выбросы, прозрачность,
  фильтры чернил, удаление мелких компонент, кисти и белые поля, пустая область,
  допустимые имена файлов и сохранение без перезаписи.
- `npm run test:ui`: полный сценарий в **настоящем Electron**, с sandboxed preload,
  модульным worker и реальным экспортом через IPC на диск. Автоматизирован только
  выбор папки в системном диалоге. На синтетических PNG и JPEG выделено по четыре
  объекта. Проверены фильтр, сравнение с оригиналом, кисть/отмена/повтор, ручная и
  дублированная рамка, имена на русском, девять выходных PNG, размеры при увеличении
  2×, отсутствие перезаписи, непрозрачные белые поля и неизменность исходного файла.
  Ошибок JavaScript в сценарии не было. Это тестовые фигуры, а не набор реальных
  документов; качество автопоиска на произвольных фотографиях этим не доказано.
- JavaScript прошёл `node --check`, изменения — `git diff --check`.
- Сборка `npm run dist:win -- --config.win.signAndEditExecutable=false` с облачными
  каталогами кэша завершилась с кодом 0. Создан единый portable NSIS `.exe` размером
  **99 413 890 байт** (около 95 МиБ). Установочный target не используется.
- SHA-256 Windows-дистрибутива Electron совпал с манифестом закреплённого npm-пакета.
- Сам portable `.exe` раскрыт как NSIS-архив. Вложенный `app-64.7z` прошёл проверку
  7-Zip; из него извлечены настоящий Windows x64 PE-файл и `resources/app.asar`.
  Они побайтно совпали с результатом упаковки; main/preload, обработка изображений,
  worker и renderer в ASAR совпали с проверенными исходниками. Dev-зависимости и
  результаты тестов в ASAR отсутствуют; лицензии Electron/Chromium присутствуют.
