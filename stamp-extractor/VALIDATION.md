## Набор примеров и пределы вывода

Примеры созданы независимо от алгоритма программным генератором с известными
масками объектов. Это **авторские тестовые документы**, а не представительная
выборка настоящих сканов. Показатели на них не означают обещания определённого
процента точности на любых изображениях. Описание: [tests/fixtures/README.md](tests/fixtures/README.md).

Используются OCR и измеряемые признаки цвета/геометрии. Это не обученный
классификатор всех видов подписей и печатей. Сильно повреждённые контуры,
декоративные надписи, небольшие таблицы и необычные рукописные штрихи могут дать
ошибки. Скрытые одноцветным наложением детали не восстанавливаются.

## Windows

Команда сборки:

```bash
ELECTRON_BUILDER_CACHE=/workspace/.cache/electron-builder npm run dist:win -- \
  --config.win.signAndEditExecutable=false \
  --config.electronDownload.cache=/workspace/.cache/electron
```

Файл — portable NSIS, с Windows x64 Electron, локальными WASM и языковыми моделями.
Сборка завершилась с кодом 0. Размер: **108,040,566 байт** (около 103 МиБ).
Portable EXE раскрыт как NSIS-архив; вложенный `app-64.7z` прошёл проверку 7-Zip.
Из него извлечены и побайтно сверены Windows x64 PE, ASAR, обе модели и OCR-worker.
Все 11 файлов приложения внутри ASAR совпадают с проверенным исходным кодом;
тестов и dev-зависимостей в поставке нет. Лицензии и WASM включены.
Таблица сертификатов EXE пуста: подписи Authenticode нет.
