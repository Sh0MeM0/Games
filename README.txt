PC Monitor Tool 1.1.0 для Windows 10/11 x64

Быстрый старт
1. Распакуйте архив целиком и дважды щёлкните pcmtool.exe. Для учёта
   требуется Windows 10 версии 1809 или новее либо Windows 11.
2. Нажмите «Начать сеанс», прочтите перечень данных и подтвердите.
   На вкладке «Обзор» показано время в приложениях за сегодня.
3. Во время учёта крестик (×) и «Свернуть» (—) сворачивают главное окно
   на панель задач. Учёт и выбранные автоснимки продолжаются. Значок
   программы на панели задач помечен красной точкой. Отдельной плавающей
   панели и значка рядом с часами нет.
4. Чтобы остановить сбор, нажмите «Остановить сеанс» в главном окне
   или в миниатюре окна на панели задач. «Выход» закрывает программу.
   При остановленном учёте крестик (×) тоже закрывает её. Блокировка,
   отключение сеанса Windows и переход в сон останавливают учёт.
   После возвращения нужно начать новый сеанс.

Как открыть окно
• Нажмите кнопку программы на панели задач или Ctrl+Alt+Shift+F9.
  Горячая клавиша действует, пока программа запущена.
• Дважды щёлкните pcmtool.exe. Если программа уже работает, откроется
  её текущее окно. Новый запуск открывает панель с остановленным учётом.
• Команда для Win+R — pcmtools (буква s в конце). Для её подключения
  остановите учёт, откройте «Настройки» → «Открыть настройки», включите
  «Открывать панель командой pcmtools в Win+R» и нажмите «Сохранить».
  Теперь нажмите Win+R, введите pcmtools и нажмите Enter. Короткое имя
  pcmtool тоже доступно, если его не использует другая программа.

Если команда Win+R открывает другой файл
Сообщение «Команда pcmtool уже зарегистрирована для другого файла»
означает, что в настройках Windows для этой учётной записи записан другой
путь к EXE. Например, он мог остаться после переноса папки.
1. Закройте работающую копию через «Выход». Дважды щёлкните по нужному
   pcmtool.exe и включите команду pcmtools в настройках, как описано выше.
   «Сохранить» обновляет устаревшую регистрацию. Файл программы
   по-прежнему называется pcmtool.exe, без s.
2. Если действующая программа занимает имя pcmtool, используйте pcmtools.
   Если занято само имя pcmtools, сообщение покажет путь к другой программе.
   Снимите флажок, чтобы сохранить остальные настройки.
3. Без короткой команды откройте нужную папку, удерживая Shift, нажмите
   правой кнопкой на pcmtool.exe и выберите «Копировать как путь».
   Вставьте полный путь в двойных кавычках в Win+R и нажмите Enter.

Данные и снимки
«Открыть папку» показывает журналы и снимки. По умолчанию они находятся
в %LOCALAPPDATA%\PCMonitor. «Экспорт в ZIP» сохраняет их копию.
• Ручной снимок на вкладке «Скриншоты» после подтверждения сохраняет
  изображения всех подключённых экранов во время активного сеанса.
• Для автоснимков нужны Windows 10 версии 1903 или новее либо Windows 11
  и поддержка Windows Graphics Capture. Включите предложение снимков
  в настройках. При каждом старте сеанса отметьте флажок автоснимков
  и укажите в системном диалоге Windows каждый нужный экран или окно.
  Нажмите «Выбрать ещё» для следующего источника и «Готово» для завершения.
  Сохраняются только выбранные источники. Системная рамка захвата остаётся
  вокруг каждого выбранного источника, в том числе при свёрнутой панели.
  Для снимков рабочего стола выбирайте весь экран. Если свернуть само
  выбранное для захвата окно, Windows может перестать выдавать кадры.
  Учёт можно остановить в любое время.

Как обновить программу
Нажмите «Выход» и дождитесь завершения работы. Распакуйте новый архив
целиком в ту же папку с заменой файлов и запустите pcmtool.exe.
