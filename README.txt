PC Monitor Tool для Windows 10/11 x64

Быстрый старт
1. Распакуйте весь архив в выбранную постоянную папку. В Проводнике дважды
   щёлкните pcmtool.exe. При первом запуске прочтите уведомление.
2. Нажмите «Начать сеанс», прочтите перечень данных и подтвердите начало
   учёта. «Обзор» показывает время в приложениях за сегодня.
3. Кнопка «Свернуть» (—) оставляет программу на панели задач. При активном
   учёте видна компактная панель состояния. Значка рядом с часами нет.
4. «Остановить сеанс» прекращает сбор и оставляет главное окно доступным.
   Крестик (×) главного окна или кнопка «Выход» закрывает программу.

Как открыть панель
• Нажмите кнопку PC Monitor Tool на панели задач.
• Нажмите Ctrl+Alt+Shift+F9 — это сочетание по умолчанию, пока программа
  работает. Другую функциональную клавишу можно выбрать в настройках.
• Дважды щёлкните pcmtool.exe в Проводнике. Если программа уже работает,
  откроется её текущее окно. При новом запуске учёт остановлен.
• Для короткой команды завершите сеанс кнопкой «Остановить сеанс».
  Откройте «Настройки» → «Открыть настройки», включите «Открывать панель
  командой pcmtool в Win+R» и сохраните. Теперь нажмите Win+R, введите
  pcmtool и нажмите Enter.
• Чтобы воспользоваться Win+R сразу, откройте папку с pcmtool.exe.
  Удерживая Shift, нажмите правой кнопкой на файл и выберите «Копировать
  как путь». Вставьте в Win+R полный путь к файлу в двойных кавычках
  и нажмите Enter. Это работает и с пробелами в названии папки.

Данные и снимки
«Открыть папку» показывает локальные журналы и снимки. По умолчанию
они находятся в %LOCALAPPDATA%\PCMonitor. «Экспорт в ZIP» сохраняет
копию данных в выбранный вами файл за пределами этой папки.
На вкладке «Скриншоты» можно сделать ручной снимок во время сеанса.
Для периодических снимков разрешите их в настройках и дайте отдельное
согласие при запуске сеанса. Блокировка Windows останавливает учёт.
