# Профиля для AutoCAD 2020–2024

Модуль для обычного AutoCAD под Windows 10/11 x64: вкладка **«Профиля»**, отдельное окно ввода и редактируемые продольные и поперечные профили каналов и прудов. AutoCAD LT и Mac не поддерживаются.

Версия **0.1.0**. В дистрибутиве отдельные сборки для каждой версии AutoCAD. Расчётное ядро проверяется автоматическими тестами; загрузка и интерфейс в настоящем AutoCAD требуют проверки на Windows. Состояние проверок перечислено в [VALIDATION.md](VALIDATION.md).

## Скачать и установить

[Скачать установщик Profiles-Setup-0.1.0.exe](https://github.com/Sh0MeM0/Games/raw/refs/heads/autocad-profiles-v0.1.0/autocad-profiles/releases/Profiles-Setup-0.1.0.exe)

1. Закройте AutoCAD, скачайте EXE и запустите установку. Требуются права администратора и .NET Framework 4.7.2 или новее.
2. Установщик помещает модуль в `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Profiles.bundle`.
3. Запустите AutoCAD. На ленте появится **«Профиля»**. Если лента скрыта, выполните `RIBBON`.
4. Нажмите «Продольный» или «Поперечные». Команды также доступны напрямую: `PROFILI`, `PROFILI_LONG`, `PROFILI_CROSS`.

Установщик не имеет подписи издателя Authenticode. Контрольные суммы находятся в [releases/SHA256SUMS.txt](releases/SHA256SUMS.txt); проверка в PowerShell: `Get-FileHash .\Profiles-Setup-0.1.0.exe -Algorithm SHA256`. Не отключайте защитные настройки AutoCAD; каталог Program Files используется для штатной загрузки модулей.

Для ручной установки доступен [архив bundle](https://github.com/Sh0MeM0/Games/raw/refs/heads/autocad-profiles-v0.1.0/autocad-profiles/releases/Profiles-Bundle-0.1.0.zip). При закрытом AutoCAD распакуйте папку `Sh0MeM0.Profiles.bundle` в `C:\Program Files\Autodesk\ApplicationPlugins`. Удаление установленной EXE версии — через «Установленные приложения» Windows. Сохранённые отдельно JSON-проекты не удаляются.

## Ввод данных

Все расстояния и отметки вводятся **в метрах**, откосы — как отношение горизонтального заложения к высоте: `1.5` означает 1,5 м по горизонтали на 1 м по вертикали (обозначение **1:1,5**). Дробные числа допускают точку или запятую. Пикет `1+25.50` означает 125,50 м. Пустая ячейка означает отсутствие данных и не превращается в нулевую отметку.

**Продольный профиль.** Введите возрастающие пикеты, отметки поверхности, левого и правого берегов, существующего дна и воды. Заполняйте только имеющиеся столбцы. Для проекта укажите проектное дно; ширина по дну и левый/правый откосы могут быть указаны отдельно как табличные данные. Между пустыми отметками линия разрывается: программа не придумывает промежуточные значения.

**Поперечники.** Создайте один или несколько профилей. В таблице задайте возрастающие поперечные расстояния и фактические отметки; расстояния могут быть отрицательными относительно оси. Для пруда можно ввести произвольный контур. Слева и справа понимаются стороны при взгляде по направлению течения.

Проект поперечника задаётся одним из двух способов:

- произвольными проектными отметками в таблице точек;
- трапецией: отметка дна, ширина дна, левое и правое заложение откосов, положение оси. Все четыре параметра трапеции нужны вместе. Откосы продолжаются до пересечения с измеренным контуром; если съёмка слишком короткая, программа просит добавить точки.

Без проектных данных строится только фактический профиль. Урез воды необязателен. Он ограничивается участками затопленного фактического контура; если фактического контура нет, используется проектный с предупреждением. Отсутствующие точки не соединяются скрытой интерполяцией.

Таблицы поддерживают вставку данных из Excel через буфер обмена (столбцы разделяются табуляцией). Перед вставкой выберите первую целевую ячейку. Кнопка примера заполняет демонстрационные данные; «Открыть» и «Сохранить» работают с отдельным JSON-проектом.

Можно сохранять незавершённые числовые данные: проверка полноты выполняется при предпросмотре и построении. После подтверждения построения данные остаются в памяти для текущего чертежа, в том числе при отмене точки вставки. Для сохранения между сеансами AutoCAD используйте JSON.

## Масштаб и оформление

Задаются горизонтальный и вертикальный масштабы, условная нулевая отметка, высота текста и коэффициент ширины. Если нулевая отметка пуста, выбирается целое значение ниже минимальной отметки. Явно введённый ноль должен быть ниже всего профиля.

Параметр «метров в единице чертежа» задаёт размер создаваемых объектов: `1` для метрических единиц модели, `0.001` для миллиметров. Он не выводится автоматически из `INSUNITS`, поскольку в исходных чертежах эти сведения могут быть недостоверны. Формулы повторяют присланные LISP-шаблоны:

```
X = расстояние / k
Y = (отметка − условный ноль) × H / (k × V)
размер 1 мм оформления = H / (1000 × k)
```

Здесь H и V — знаменатели масштабов, k — метров в единице чертежа. Печать на бумаге должна учитывать этот коэффициент; команда не меняет настройки листа или печати. Оформление использует текущий текстовый стиль AutoCAD: выберите стиль с кириллицей, например Arial. Основной размер текста — 2,5 мм. Продольная колонка заголовков — 55 мм; поперечная — 38 мм. Пустые строки можно скрыть или оставить для ручного оформления.

Готовый профиль состоит из обычных полилиний, текстов и окружностей на слоях `PROF_*`. Проект красный, вода синяя, фактические данные и таблица имеют отдельные слои. Точку вставки укажите после подтверждения окна. Вставка учитывает текущую ПСК; отмена выбора точки ничего не добавляет. Одной командой `UNDO` можно отменить построение.

Предпросмотр показывает геометрию и структуру таблицы. Окончательные метрики шрифта определяет AutoCAD. При плотных пикетах увеличьте горизонтальный масштаб изображения (уменьшите знаменатель) или разбейте профиль на части; программа сообщает о тесных колонках.

Модуль не рассчитывает гидравлику, объёмы земляных работ, ведомости или соответствие нормам. Фактические отметки берутся только из введённых данных. Результат нужно проверить перед выпуском чертежа. Исходный DWG пользователя и сторонняя программа MDSTools в дистрибутив не входят.

## Сборка из исходников

Нужны .NET SDK 8.0.426, Python 3 и NSIS 3.11. SDK AutoCAD загружается из официальных пакетов NuGet `AutoCAD.NET`, `AutoCAD.NET.Core`, `AutoCAD.NET.Model`; DLL Autodesk в установщик не включаются. Команда из этой папки:

```bash
python3 build.py
```

Скрипт сначала запускает тесты, затем собирает пять вариантов модуля и создаёт EXE, ZIP и SHA-256 в `releases`. Параметры `--dotnet` и `--makensis` задают пути к инструментам. При локально распакованном NSIS укажите переменную `NSISDIR` на его каталог `share/nsis`.
