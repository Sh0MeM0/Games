# Проверки версии 0.2.0

Проверено в Linux 23 октября 2026 года:

- 119 тестов расчётного ядра: интерполяция по неравным расстояниям без экстраполяции, сохранение исходных пустых ячеек, пересчёт после изменения опорных отметок, перенос отметок в поперечник, определение центра, геометрия откосов и воды, масштабы и единицы, нулевой горизонт, стили линий и подписей, отсутствие точечных кружков, три разных шаблона, JSON версии 2 и миграция версии 1. Все пройдены.
- Отдельный тест по примеру пользователя: ПК 0 / 63,49 / 82,94; проектные отметки 144,21 / пусто / 144,30. Получается одна диагональ в строке уклона между исходными точками, подписи 1,1‰ и 82,94 м; промежуточная отметка вычисляется, но не становится исходной. Проверено и обратное направление уклона.
- 6 проверок упаковки классического меню: независимая загрузка CUIX для 2020–2024, меню «Профиля», ссылки на команды во всех компонентах, целостность частей OPC/ZIP и XML, отсутствие замены рабочего пространства, воспроизводимость CUIX.
- Пять отдельных Release-сборок для AutoCAD 2020–2024 с официальными SDK. Установщик NSIS 3.11 содержит пять наборов собственных DLL, Newtonsoft.Json, частичный CUIX, документацию и примеры; DLL Autodesk не распространяются.
- Четыре синтетических примера сформированы действующим ядром: подчистка, новый канал, НВК и поперечники. JSON сохранены и прочитаны заново, DXF проверены аудитом ezdxf без ошибок и исправлений, изображения просмотрены. Кружков на линиях нет. Эти изображения показывают результат расчётного ядра, а не работающий AutoCAD.
- Исходники хранения DWG и перестроения проверены отдельно: данные сохраняются в собственном разделе словаря DWG с проверками версии, размера и контрольной суммы; замена геометрии выполняется одной транзакцией и проверяет принадлежность прежних объектов. Проверка кода не заменяет проверку внутри AutoCAD.
- Режим обслуживания установщика скомпилирован NSIS: при повторном запуске выбор исправления или удаления; удаление не требует .NET, проверяет занятость файлов и не продолжает установку после успешного удаления. Пользовательские DWG и отдельно сохранённые JSON не входят в список удаляемых файлов.

Версии SDK: 2020 — 23.1.0; 2021 — 24.0.0; 2022 — 24.1.51000; 2023 — 24.2.0; 2024 — 24.3.0. Целевая среда — .NET Framework 4.7.2, x64.

## Проверка в AutoCAD на Windows

Эти проверки остаются необходимыми и не заменяются Linux-тестами:

1. Закрыть AutoCAD, установить EXE поверх 0.1.x, запустить каждую поддерживаемую версию. В классическом интерфейсе проверить меню «Профиля», а при открытой ленте — вкладку. Проверить PROFILI_MENU после смены рабочего пространства.
2. Создать два именованных проекта. Заполнить продольную таблицу, оставить промежуточные отметки пустыми и проверить расчётные ячейки курсивом. Изменить опорную отметку, затем задать собственную промежуточную. Проверить пикеты с десятичной запятой и вставку из Excel.
3. По очереди выбрать «Подчистка канала», «Новый канал», «Сети НВК». Проверить состав таблиц, скрытие и сохранение неактивных столбцов, цвета, штриховые линии, диагональ и подписи уклона. Для НВК проверить отдельные проектную землю и лоток трубы.
4. Создать поперечник из списка пикетов. Проверить перенесённые отметки, ввести реальные расстояния берегов и дна, добавить промежуточную точку и выполнить контекстную интерполяцию. Проверить определение центра плоского и наклонного дна. При обновлении по пикету ручные точки должны сохраниться.
5. Сохранить DWG, закрыть AutoCAD и открыть файл снова. Проверить оба проекта, исходные пустые ячейки, таблицы поперечников и выбранный шаблон. Проверить отдельный экспорт/импорт JSON и явно включаемое автосохранение JSON.
6. Построить продольный профиль и набор поперечников. Изменить отметки и выполнить «Перестроить на месте»: прежние объекты этого проекта и типа заменяются, точка вставки и ПСК сохраняются. «Построить / переместить» меняет место. Другой проект, другой тип профиля и сторонние объекты остаются.
7. Проверить один UNDO, удалённые вручную объекты прежнего профиля, заблокированные слои, другую ПСК и пространство листа. При ошибке старое построение должно сохраниться. Построения 0.1.x без связи с проектом автоматически не удаляются.
8. Проверить незавершённые данные, закрытие окна с ошибочным числом, отмену выбора точки вставки, сохранение чертежа только для чтения. Сообщение об ошибке не должно означать успешное сохранение.
9. Повторно запустить EXE: выполнить «Исправить», затем «Удалить». Проверить отмену удаления, занятые файлы при открытом AutoCAD, удаление через Windows и повторную установку. Убедиться, что DWG/JSON сохранились.
10. Проверить текст при разных DPI и шрифтах, масштабы печати и действие CTB/STB на цвет ACI 7.

Реальная загрузка, WinForms, сохранение/перестроение/UNDO в DWG и работа установщика на Windows не запускались в этой Linux-среде. Установщик не имеет подписи Authenticode.
