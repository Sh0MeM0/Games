# Дневник зала — Android-приложение для учёта тренировок

Готовый файл для установки: [`release/dnevnik-zala-1.4.apk`](release/dnevnik-zala-1.4.apk)
(7 616 337 байт, SHA-256 `06c9128dfc39b38f41e3c4e7c2fd13b5ab68afc24cf06cc13e1a664b6076035e`).

Требуется Android 8.0 или новее. Разрешения не нужны, все данные и фото хранятся на телефоне: приложение работает и без интернета. Интернет нужен только кнопке ▶ «Видео».

## Что нового в версии 1.4

- **478 упражнений вместо 220**, у каждого два настоящих фото (начало и конец движения). По группам:
  - грудь — 71, спина — 58, ноги — 90, ягодицы — 96, плечи — 82;
  - бицепс — 55, трицепс — 55, пресс — 55, предплечья — 25;
  - икры — 13, трапеции — 11, кардио — 8.

  Одно упражнение может входить в несколько групп. Например, приседания есть и в «Ногах», и в «Ягодицах».
- **По оборудованию**: штанга — 123, гантели и гири — 138, блок — 77, тренажёр — 61, свой вес — 66, другое — 13.
- **Фото сжаты в WebP.** Упражнений стало больше чем вдвое, а APK вырос с 6,6 до 7,6 МБ. Прежние 438 фото в JPEG занимали 6,4 МБ, теперь все 954 фото — 7,3 МБ.
- **Порядок в списке.** В списке по группе сначала идут 91 основное упражнение с подробной техникой, затем остальные. Фильтр оборудования помогает быстро сузить выбор.

Предложение пользователя взять фото с atletiq.com не выполнено. Это коммерческий проект, разрешения на копирование его фото найти не удалось, а без согласия правообладателя копировать их в приложение и публичный репозиторий нельзя. Вместо этого расширен набор из открытого источника (см. «Откуда фото и упражнения»).

Версия 1.4 подписана тем же ключом, что и 1.0–1.3: ставится поверх без потери данных.

## Как установить

1. Скачайте `dnevnik-zala-1.4.apk` на телефон (например, со страницы этого файла на GitHub — кнопка «Download raw file»).
2. Откройте его и разрешите установку из этого источника.
3. Google Play Защита может предупредить про неизвестного разработчика. Так бывает с любым APK не из Google Play: нажмите «Всё равно установить».

## Как пользоваться

1. **Календарь**: дни с тренировками закрашены. Нажмите на дату.
2. **«Добавить тренажёр»** (кнопка внизу экрана дня):
   - введите группу мышц («грудь», «спина», «трицепс»…) или нажмите её кнопку;
   - при желании сузьте выбор фильтром оборудования;
   - нажмите на фото нужного упражнения.

   Можно также ввести своё название и нажать «Добавить».
3. **Подходы**: карточки тренажёров свёрнуты (название + итог). Нажмите, чтобы раскрыть и записать повторения и вес. Для упражнений с собственным весом графа называется «Доп. вес» (10 = +10 кг, пусто = без утяжеления).
4. **Значки сравнения** с прошлой тренировкой: зелёная стрелка вверх — лучше, красная вниз — хуже, «=» — без изменений. Нажатие объясняет причину.
5. **Фото** слева от названия: нажмите, чтобы выбрать другое упражнение-фото. **«Техника и описание ›»** — два фото, мышцы, оборудование, техника (для 91 основного упражнения) и видео.
6. **Вкладка «Прогресс»**: проценты улучшений и ухудшений по месяцам.
7. **Меню ⋮ на главном экране**: «Мои тренажёры», резервная копия и восстановление.

## Откуда фото и упражнения

- **Фото и список дополнительных упражнений** взяты из открытого набора [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (переработка [exercises.json](https://github.com/wrkout/exercises.json)). Авторы опубликовали его как общественное достояние (The Unlicense). Кто сделал исходные фотографии, в наборе не указано, поэтому подтвердить права на них независимо я не могу (подробнее — `THIRD_PARTY_NOTICES.md`).
- **Соответствие фото и названий** проверено просмотром всех 478 пар «фото — русское название» на обзорных листах; найденные неточности в названиях исправлены.
- **Русские названия** составлены для приложения (список дополнительных — `tools/more_exercises.py`). Техника написана для 91 основного упражнения; для остальных 387 есть фото, мышцы, оборудование и кнопка видео.
- **Подбор по названию** работает на телефоне без интернета и без нейросети: регистр не важен, учитываются окончания слов, синонимы, английские названия и опечатки. Тест проверяет 115 вариантов написания, а также что каждое из 478 названий находит именно своё упражнение и у каждого есть оба фото.
- **Видео**: поиск YouTube по запросу «техника <название>». Подборку делает YouTube, приложение её не проверяет.

## Сборка из исходников

Сборка без Gradle/Android SDK: инструменты из пакетов Ubuntu 24.04, платформа Android 14 (API 34) — из Maven Central (`org.robolectric:android-all:14-robolectric-10818077`, SHA-1 проверяется в `tools/fetch-sdk.sh`).

```bash
sudo apt-get install -y openjdk-21-jdk-headless aapt dalvik-exchange zipalign apksigner
./build.sh                       # результат: release/dnevnik-zala-<версия>.apk
python3 tools/photo_catalog.py   # скачать фото, сжать в WebP и создать PhotoData.java (нужен Pillow)
```

Тесты (41 шт.: сравнение, доп. вес, прогресс, подбор и группы, фото, база данных и её обновление, экраны через Robolectric 3.8 на Android 8.1):

```bash
sudo apt-get install -y openjdk-8-jdk-headless
mkdir -p .sdk/robolectric && curl -fL -o .sdk/robolectric/android-all-8.1.0-robolectric-4611349.jar \
  https://repo1.maven.org/maven2/org/robolectric/android-all/8.1.0-robolectric-4611349/android-all-8.1.0-robolectric-4611349.jar
./build.sh && (cd test && gradle test)
```

## Ключ подписи

Файл ключа (`keystore/gymlog.jks`) в репозиторий не добавлен: репозиторий публичный. Если файла нет, `build.sh` создаёт новый ключ.

Android ставит новую версию поверх старой только при подписи тем же ключом. Если ключ другой: сделайте резервную копию в приложении, удалите старое приложение, установите новое и восстановите копию.

## Устройство кода

- `src/app/gymlog/Catalog.java` — 91 основное упражнение с техникой, группы мышц, оборудование;
- `src/app/gymlog/PhotoData.java` — фото для всех упражнений и ещё 387 упражнений (создаётся `tools/photo_catalog.py` из списков в нём и в `tools/more_exercises.py`); фото лежат в `assets/ex/` (WebP);
- `src/app/gymlog/Matcher.java` — подбор по названию и группе мышц;
- `src/app/gymlog/Compare.java` — сравнение подходов; `Progress.java` — статистика;
- `src/app/gymlog/Db.java` — база SQLite и резервная копия;
- `src/app/gymlog/DayActivity.java` — экран дня и окно добавления с плитками фото; `MainActivity.java`, `ExercisesActivity.java`, `ExerciseInfoActivity.java`;
- `test/` — тесты JUnit + Robolectric.
