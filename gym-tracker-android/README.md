# Дневник зала — Android-приложение для учёта тренировок

Готовый файл для установки: [`release/dnevnik-zala-1.1.apk`](release/dnevnik-zala-1.1.apk)
(1 311 506 байт, SHA-256 `fb5cc2d17e6e0349a42bf80dba2cb8eaf2282c06eb9c39fe43679ca151546b0d`).

Требуется Android 8.0 или новее. Интернет и разрешения не нужны, все данные хранятся только на телефоне. Интернет используется только кнопкой «Найти видео», если вы её нажмёте.

## Что нового в версии 1.1

- **Вкладка «Прогресс»**: для каждого месяца показаны проценты улучшений, ухудшений и подходов без изменений, а также изменение максимального веса по каждому тренажёру.
- **Картинки и справочник**: по названию тренажёра автоматически подбирается картинка из встроенного справочника (43 упражнения). Нажатие на картинку открывает выбор другой. По ссылке «Техника и описание ›» открываются работающие мышцы, техника, частые ошибки и поиск видео на YouTube.
- **Фоновая музыка**: спокойная мелодия; кнопка с нотой в верхней панели включает и выключает её.

Версия 1.1 подписана тем же ключом, что и 1.0, поэтому устанавливается поверх старой без потери данных. Уже сохранённые тренажёры получат картинки автоматически.

## Как установить

1. Скачайте файл `dnevnik-zala-1.1.apk` на телефон (например, со страницы этого файла на GitHub — кнопка «Download raw file»).
2. Откройте его. Android попросит разрешить установку из этого источника (браузера или файлового менеджера) — разрешите.
3. Google Play Защита может предупредить, что приложение от неизвестного разработчика: это обычное поведение для любого APK не из Google Play. Нажмите «Всё равно установить».

## Как пользоваться

1. **Календарь** (вкладка «Календарь»). Дни, в которые вы тренировались, закрашены. Сегодняшний день обведён. Стрелки ‹ › листают месяцы, нажатие на название месяца возвращает к текущему.
2. **Нажмите на дату** — откроется экран этого дня. Кнопкой «+ Добавить тренажёр» введите название тренажёра (например, «Жим лёжа»). Название запоминается для следующих тренировок.
3. **Под названием тренажёра** записывайте подходы: в каждой строке — номер подхода, количество повторений и вес в кг. Кнопка «+ Подход» добавляет следующий подход. Всё сохраняется сразу при вводе, кнопки «Сохранить» нет.
4. **В другой день** нажмите «+ Добавить тренажёр» и выберите тренажёр из списка сохранённых. Сразу появится столько же подходов, сколько было в прошлый раз, а серым подсказкой в полях будут видны прошлые повторения и вес.
5. **Значки сравнения** рядом с каждым подходом (сравнивается с тем же подходом в прошлый раз, когда вы делали этот тренажёр):
   - зелёная стрелка вверх — стало лучше;
   - красная стрелка вниз — стало хуже;
   - знак «=» — без изменений;
   - синяя звёздочка — сравнивать не с чем (первая запись или подхода в прошлый раз не было).

   Нажмите на стрелку или на значок «!» рядом с ней — появится примечание с причиной, например:
   «Вес меньше на 5 кг: 10 ноября 2026 вес был больше — 50 кг.» или «Повторений больше на 2: 12 ноября 2026 было 10.»

   Правило: сначала сравнивается вес; если вес тот же — количество повторений. Если вес вырос, а повторений стало меньше, стрелка показывает вверх, и примечание это объясняет.
   Значок рядом с названием тренажёра — итог по всем подходам (оранжевый значок — часть подходов лучше, часть хуже).
6. **Картинка слева от названия** подобрана по названию тренажёра. Если она не подходит или её нет (значок с плюсом), нажмите на неё и выберите нужную; сверху списка — самые похожие варианты, есть поиск и вариант «Без картинки». Выбранная вручную картинка не меняется при переименовании.
7. **«Техника и описание ›»** под названием (или меню ⋮ → «Описание и техника») — дополнительная информация, которая не мешает записи подходов.
8. **Вкладка «Прогресс»**. Для каждого месяца:
   - процент улучшений, ухудшений и «без изменений»;
   - сравнение с предыдущим месяцем;
   - по каждому тренажёру — сколько подходов стало лучше или хуже и изменение максимального веса, например «макс. вес 50 → 55 кг (+10%)».

   Как считается: каждый подход сравнивается с тем же подходом прошлой тренировки на этом тренажёре по тому же правилу, что и стрелки. Процент улучшений = число подходов, ставших лучше ÷ число сравнённых подходов × 100. Проценты округлены так, что в сумме дают ровно 100.
9. **Музыка**: кнопка с нотой в верхней панели. Выбор запоминается. Музыка играет, только пока приложение открыто, и встаёт на паузу во время звонков. Если при открытии приложения уже играет другая музыка (например, ваш плейлист), наша сама не включится.
10. **Меню ⋮ на главном экране**:
    - «Мои тренажёры» — картинки, описание, переименование, удаление, история;
    - «Сохранить резервную копию» и «Восстановить из копии» — файл JSON, например для переноса на новый телефон.

## Как устроен подбор картинок (честно)

Подбор работает **на самом телефоне, без интернета и без нейросети**. Название, которое вы ввели, сравнивается с названиями и синонимами 43 упражнений встроенного справочника:
- регистр не важен, «ё» = «е», «э» = «е»;
- окончания слов отбрасываются: «гантелей» = «гантели»;
- учитываются сокращения («тяга верх. блока») и опечатки.

Картинка ставится автоматически только при уверенном совпадении (оценка ≥ 0,7 из 1). Иначе выбор остаётся за вами. Тест `MatcherTest` проверяет 80 типичных вариантов написания.

- **Картинки** — схематичные человечки, которые программа рисует сама (`tools/gen_pictograms.py`). Полупрозрачная фигура — начало движения, яркая — конец. Чужих изображений в приложении нет.
- **Описания и техника** — общие, широко распространённые рекомендации, составленные для этого приложения. С конкретным источником они не сверялись, это не медицинская консультация. При травмах или боли обратитесь к тренеру или врачу.
- **Видео**: кнопка открывает поиск YouTube по запросу «техника <название упражнения>». Подборку видео делает YouTube, приложение её не проверяет.

## Музыка

Мелодия оригинальная: её синтезирует программа `tools/gen_music.py` без готовых сэмплов. Это спокойный lo-fi, 82 удара в минуту, петля 94 с без шва на стыке. В приложение она входит файлом `res/raw/music.ogg` (OGG Vorbis, около 1,2 МБ).

## Сборка из исходников

Сборка не использует Gradle/Android SDK: инструменты берутся из пакетов Ubuntu 24.04, а платформа Android 14 (API 34) — из Maven Central (артефакт `org.robolectric:android-all:14-robolectric-10818077`, контрольная сумма SHA-1 проверяется в `tools/fetch-sdk.sh`).

```bash
sudo apt-get install -y openjdk-21-jdk-headless aapt dalvik-exchange zipalign apksigner
./build.sh          # результат: release/dnevnik-zala-<версия>.apk
```

Пересоздать картинки и музыку (необязательно — готовые файлы уже лежат в `res/`):

```bash
python3 tools/gen_pictograms.py preview.html          # res/drawable/ex_*.xml + лист предпросмотра
python3 tools/gen_music.py music.wav && ffmpeg -i music.wav -c:a libvorbis -q:a 3 res/raw/music.ogg   # нужен numpy
```

Тесты (34 шт.: сравнение, прогресс, подбор картинок, база данных и её обновление с версии 1, экраны через Robolectric 3.8 на Android 8.1):

```bash
sudo apt-get install -y openjdk-8-jdk-headless
# один раз положить android-all 8.1 в .sdk/robolectric/:
mkdir -p .sdk/robolectric && curl -fL -o .sdk/robolectric/android-all-8.1.0-robolectric-4611349.jar \
  https://repo1.maven.org/maven2/org/robolectric/android-all/8.1.0-robolectric-4611349/android-all-8.1.0-robolectric-4611349.jar
./build.sh && (cd test && gradle test)
```

## Ключ подписи

Файл ключа подписи (`keystore/gymlog.jks`) в репозиторий не добавлен: репозиторий публичный, а по ключу любой мог бы выпустить «обновление» приложения. Если файла нет, `build.sh` создаёт новый ключ.

Android устанавливает новую версию поверх старой только при подписи тем же ключом. Если APK подписан другим ключом: сохраните резервную копию в приложении (меню ⋮ → «Сохранить резервную копию»), удалите старое приложение, установите новое и восстановите копию.

## Устройство кода

- `src/app/gymlog/Compare.java` — правила сравнения подходов и тексты примечаний;
- `src/app/gymlog/Progress.java`, `ProgressScreen.java` — статистика по месяцам и вкладка «Прогресс»;
- `src/app/gymlog/Catalog.java`, `Matcher.java` — справочник упражнений и подбор по названию;
- `src/app/gymlog/Music.java`, `BaseActivity.java` — фоновая музыка и кнопка в верхней панели;
- `src/app/gymlog/Db.java` — база SQLite (тренажёры, дни, подходы, картинки), резервная копия JSON;
- `src/app/gymlog/MainActivity.java` — календарь и вкладки; `DayActivity.java` — экран дня; `ExercisesActivity.java` — список тренажёров; `ExerciseInfoActivity.java` — описание и техника;
- `tools/` — генераторы картинок и музыки, подготовка платформы Android;
- `test/` — тесты JUnit + Robolectric.
