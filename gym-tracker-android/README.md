# Дневник зала — Android-приложение для учёта тренировок

Готовый файл для установки: [`release/dnevnik-zala-1.2.apk`](release/dnevnik-zala-1.2.apk)
(196 342 байта, SHA-256 `e562aaa66d710446d34854a55294727d52c037eff1d03e09541611624736d0bc`).

Требуется Android 8.0 или новее. Разрешения не нужны, все данные хранятся только на телефоне. Интернет используется только кнопкой «Видео», если вы её нажмёте.

## Что нового в версии 1.2

- **Карточки тренажёров свёрнуты.** На экране дня видно название, картинку и короткий итог («3 подхода: 10 × 50 кг · …»). Нажатие на название или на стрелку раскрывает подходы. В меню ⋮ вверху есть «Развернуть все» и «Свернуть все».
- **Кнопка «Добавить тренажёр» закреплена внизу экрана**, листать до неё не нужно. Пока открыта клавиатура, кнопка прячется.
- **«Доп. вес» для упражнений с собственным весом**: скручивания, подтягивания, брусья, отжимания, планка, подъёмы ног, гиперэкстензия, обратные отжимания. Вместо «Вес, кг» там графа «Доп. вес, кг»: пишите только утяжеление (10 = +10 кг) или оставляйте пусто. Для любого тренажёра режим переключается в меню ⋮ у карточки.
- **Справочник вырос с 43 до 91 упражнения**, добавлены варианты:
  - шраги с гантелями, со штангой, в Смите;
  - тяга нижнего блока к поясу, широким хватом, одной рукой, рычажная, с упором грудью, Т-гриф;
  - трицепс на блоке: прямая рукоять, обратный хват, канат, одной рукой, из-за головы;
  - разгибание гантели из-за головы, кикбэк, трицепс в тренажёре и др.
- **Поиск по группе мышц.** В окне «Добавить тренажёр» напишите «грудь» или нажмите кнопку группы (Грудь, Спина, Ноги, Плечи, Бицепс, Трицепс, Пресс…). Появится список упражнений этой группы с картинками, задействованными мышцами и красной кнопкой ▶. Она открывает поиск видео с техникой на YouTube.
- **Музыка убрана.**

Версия 1.2 подписана тем же ключом, что и 1.0 и 1.1, поэтому устанавливается поверх них без потери данных.

## Как установить

1. Скачайте `dnevnik-zala-1.2.apk` на телефон (например, со страницы этого файла на GitHub — кнопка «Download raw file»).
2. Откройте его и разрешите установку из этого источника.
3. Google Play Защита может предупредить про неизвестного разработчика. Так бывает с любым APK не из Google Play: нажмите «Всё равно установить».

## Как пользоваться

1. **Календарь** (вкладка «Календарь»): дни с тренировками закрашены, сегодня обведено. Нажмите на дату, чтобы открыть день.
2. **Добавить тренажёр** — кнопка внизу экрана дня. Можно:
   - выбрать из «Ваших тренажёров»;
   - выбрать из справочника, введя название или группу мышц;
   - просто ввести своё название и нажать «Добавить».
3. **Подходы**: в раскрытой карточке каждая строка — номер подхода, повторения и вес (или доп. вес). «+ Подход» добавляет строку. Всё сохраняется сразу. Серые подсказки в полях — то, что было в прошлый раз.
4. **Значки сравнения** с тем же подходом прошлой тренировки на этом тренажёре: зелёная стрелка вверх — лучше, красная вниз — хуже, «=» — без изменений, синяя звёздочка — сравнивать не с чем. Нажатие на значок или «!» объясняет причину, например «Вес меньше на 5 кг: 10 ноября 2026 вес был больше — 50 кг». Сначала сравнивается вес (или доп. вес), а если он тот же — повторения.
5. **Картинка** слева от названия: нажмите, чтобы выбрать другую (есть поиск и вариант «Без картинки»). **«Техника и описание ›»** в раскрытой карточке — мышцы, техника, частые ошибки, поиск видео.
6. **Вкладка «Прогресс»**: по каждому месяцу проценты улучшений, ухудшений и «без изменений», сравнение с прошлым месяцем и изменение максимального веса по тренажёрам. Формула показана внизу вкладки.
7. **Меню ⋮ на главном экране**:
   - «Мои тренажёры»;
   - «Сохранить резервную копию» и «Восстановить из копии» (файл JSON).

## Как устроен подбор картинок и поиск

Подбор работает на телефоне, без интернета и без нейросети. Название сравнивается с названиями и синонимами 91 упражнения встроенного справочника:
- регистр не важен, «ё» = «е»;
- окончания слов отбрасываются;
- учитываются сокращения и опечатки.

Картинка ставится автоматически только при уверенном совпадении (оценка ≥ 0,7 из 1). Если введена только группа мышц («грудь»), картинка не ставится, а показывается список упражнений этой группы. Тест `MatcherTest` проверяет 115 вариантов написания.

- **Картинки** — схематичные человечки, которых рисует программа `tools/gen_pictograms.py` (82 рисунка; некоторые похожие варианты делят один рисунок, например прямой и обратный хват на блоке). Чужих изображений нет.
- **Описания и техника** — общие рекомендации, составленные для приложения. С конкретным источником построчно не сверялись, это не медицинская консультация.
- **Список вариантов** упражнений сверялся с результатами веб-поиска. Сами страницы из среды сборки открыть не удалось: сетевые правила её не пускали. Примеры источников из поиска: [шраги — sportmail.ru](https://sportmail.ru/article/fitness/70292821/), [шраги в Смите — fitwill.app](https://fitwill.app/ru/exercise/5223/smith-wide-shrug/), [тяга горизонтального блока — lifehacker.ru](https://lifehacker.ru/tyaga-gorizontalnogo-bloka/), [тяга одной рукой в тренажёре — fitwill.app](https://fitwill.app/ru/exercise/1235/lever-one-arm-seated-row-seated-row-machine/), [упражнения на бицепс — lifehacker.ru](https://lifehacker.ru/uprazhneniya-na-biceps/amp/), [концентрированные сгибания — mentoday.ru](https://www.mentoday.ru/fitness/theory/chem-zamenit-koncentrirovannye-sgibaniya-na-biceps-i-kakih-oshibok-ne-stoit-dopuskat/), [упражнения на трицепс — fb.ru](https://fb.ru/article/26479/uprajneniya-na-tritseps---chto-k-chemu), [упражнения на грудь — lifehacker.ru](https://lifehacker.ru/health/kachestvo-zhizni/uprazhneniya-na-grud/amp/).
- **Видео**: кнопка открывает поиск YouTube по запросу «техника <название упражнения>». Подборку делает YouTube, приложение её не проверяет.

## Сборка из исходников

Сборка не использует Gradle/Android SDK: инструменты из пакетов Ubuntu 24.04, платформа Android 14 (API 34) — из Maven Central (`org.robolectric:android-all:14-robolectric-10818077`, SHA-1 проверяется в `tools/fetch-sdk.sh`).

```bash
sudo apt-get install -y openjdk-21-jdk-headless aapt dalvik-exchange zipalign apksigner
./build.sh          # результат: release/dnevnik-zala-<версия>.apk
python3 tools/gen_pictograms.py preview.html   # пересоздать картинки (необязательно)
```

Тесты (40 шт.: сравнение, доп. вес, прогресс, подбор и группы мышц, база данных и её обновление со старых версий, экраны через Robolectric 3.8 на Android 8.1):

```bash
sudo apt-get install -y openjdk-8-jdk-headless
mkdir -p .sdk/robolectric && curl -fL -o .sdk/robolectric/android-all-8.1.0-robolectric-4611349.jar \
  https://repo1.maven.org/maven2/org/robolectric/android-all/8.1.0-robolectric-4611349/android-all-8.1.0-robolectric-4611349.jar
./build.sh && (cd test && gradle test)
```

## Ключ подписи

Файл ключа подписи (`keystore/gymlog.jks`) в репозиторий не добавлен: репозиторий публичный. Если файла нет, `build.sh` создаёт новый ключ.

Android ставит новую версию поверх старой только при подписи тем же ключом. Если ключ другой: сохраните резервную копию (меню ⋮ → «Сохранить резервную копию»), удалите старое приложение, установите новое и восстановите копию.

## Устройство кода

- `src/app/gymlog/Compare.java` — правила сравнения подходов и тексты примечаний (в т. ч. для доп. веса);
- `src/app/gymlog/Progress.java`, `ProgressScreen.java` — статистика по месяцам;
- `src/app/gymlog/Catalog.java`, `Matcher.java` — справочник упражнений, группы мышц, подбор по названию;
- `src/app/gymlog/Db.java` — база SQLite (тренажёры, дни, подходы, картинки, режим веса), резервная копия JSON;
- `src/app/gymlog/DayActivity.java` — экран дня (свёрнутые карточки, окно добавления с поиском); `MainActivity.java` — календарь и прогресс; `ExercisesActivity.java`, `ExerciseInfoActivity.java`;
- `tools/` — генератор картинок, подготовка платформы Android;
- `test/` — тесты JUnit + Robolectric.
