# Таксация Лайт

Свободный и облегчённый аналог расчётов программы «ТАКСАЦИЯ-АВТО 4.2»: ведомости
существующих, удаляемых и пересаживаемых деревьев и кустарников, компенсационные выплаты
или посадки, баланс, объёмы древесины, цветники, газоны и травяной покров.

Есть три варианта с одинаковым расчётом. Лицензионного ключа и макросов нет, защиты листов
нет. Строки можно свободно добавлять и удалять.

| Вариант | Файл | Как запустить |
|---|---|---|
| Веб-приложение | [`web/taksaciya.html`](web/taksaciya.html) | Скачать и открыть двойным щелчком в Chrome, Edge, Firefox или Яндекс Браузере. Работает без интернета |
| Настольная программа | [`desktop/taksaciya_app.py`](desktop/taksaciya_app.py) | Windows: `TaksaciyaLite.exe` (собирается автоматически, см. ниже). С установленным Python: `python desktop/taksaciya_app.py` |
| Книга Excel | [`excel/Таксация-Лайт.xlsx`](excel/Таксация-Лайт.xlsx) | Открыть в Excel 2010 и новее или в LibreOffice Calc. Только формулы, без макросов |

Проекты веб- и настольной версий хранятся в одном формате (`.json`), поэтому файл
открывается в обеих. Обе версии импортируют файлы старой программы: `.xlsm`
ТАКСАЦИЯ-АВТО переносится вместе с ведомостью, настройками К1–К4, причинами вырубки,
цветниками и газонами, данными объекта, календарём базовых величин и собственными
породами.

## Почему быстрее

Исходный файл весит 22 МБ. Скрытый лист «УДд» отформатирован до строки 1 048 489 и
занимает 205 МБ в распакованном виде. Строка расчёта — около 130 формул, некоторые
длиной до 7 000 символов. Формулы ссылаются на целые столбцы (`J:J`, `D:D`), а лист
«породы» использует «летучую» функцию `OFFSET`, которая пересчитывается при каждом
изменении.

В Таксации Лайт:

* веб-версия весит около 250 КБ и считает весь объект за доли секунды;
* настольная программа написана на чистом Python, без внешних библиотек;
* книга Excel весит 1,5 МБ на 2 000 строк. Диапазоны ограничены, летучих функций нет,
  повторяющиеся формулы хранятся как общие.

## Как вносить деревья и кустарники

* **Кол-во** — штук. Для участка поросли — площадь в м², для живой изгороди — длина
  в п.м. Пустое поле — 1 шт.
* **№ нач.** — начальный номер по плану, если нумерация идёт с разрывом. Иначе номера
  идут подряд, как в оригинале: «1-1», «2-3», «4-4».
* **Диаметр, см**:
  * целое число;
  * многоствольное дерево — через запятую: `20,15,12`, до 27 стволов;
  * кустарник и живая изгородь — `-`;
  * участок поросли деревьев — `0-4`;
  * мелкие деревья — `до1`, `до4`;
  * высаженные в целях озеленения — `**до1`, `**до4`.
* **Состояние**: хор., уд., плох., ненадл. Пустое поле — значение по умолчанию из настроек.
* **Действие**: В — вырубить, П — пересадить, пусто — сохранить. Для вырубки нужна причина.
* **Инд. К** — номера коэффициентов, которые для этой строки меняются на обратные
  (например `24`), или «без компенcации».
* **Примечание** попадает в наименование в скобках. Запись вида `V=50%` уменьшает
  массу кустарника.

Служебные строки справочника: «Уч-к поросли дер.», «Уч-к поросли куст.»,
«\*Уч-к поросли дер. у дорог», «\*Уч-к поросли куст. у дорог», «Однорядная живая
изгородь», «Двухрядная живая изгородь».

## Что перенесено из оригинала

Все справочные значения выгружены из файла программы, ничего не задано «на глаз».
Источник каждой таблицы указан в [`core/reference.json`](core/reference.json), в поле
`sources`.

| Данные | Лист и ячейки оригинала |
|---|---|
| Библиотека пород: 363 вида — тип, куст или дерево, твёрдость древесины, инвазивность, размер кома | `Библ.ОРМ!A2:J560` |
| Тарифы деревьев по диаметру (хвойные, медленнорастущие, быстрорастущие и плодовые, малоценные) | `УДд!AC18:AF47` |
| Высаженные для озеленения, поросль, живая изгородь, кустарники по высоте | `УДд!AF48:AF70` |
| Нормы компенсационных посадок деревьев и кустарников | `УДд!AA3:AN11` |
| Таблицы объёмов древесины (мягкие, хвойные, твёрдые породы) и плотности | `УДд!AB96:AM183` |
| Коэффициенты размера кома по типам пород | `породы!H3:R17` |
| Календарь базовых величин | `базовая!A2:C30` |
| Цветники, газоны, травяной покров (баз.вел./м²) | `ЦвГаТр!K3:L42` |
| Причины вырубки, «компенсировать типами», настройки по умолчанию | `СУЩд!I1:V20` |

Базовая величина выбирается по дате расчёта из календаря. Календарь можно дополнить:
в веб- и настольной версии — на вкладке «Справочники», в Excel — на листе
«Справочник», колонки X–Z. Можно также ввести своё значение для конкретного проекта.

## Как проверена точность

1. Исходный файл пересчитан в LibreOffice с русской локалью. Результат совпал с
   сохранёнными значениями Excel автора во всех 12 089 ячейках листа «УДд» и на
   остальных листах. Для этого в рабочей копии сделаны две правки совместимости:
   кавычки в имени листа `Библ.ОРМ` и ссылка `J:J` в MATCH заменена на ячейку своей
   строки.
2. Восемь наборов случайных данных — около 1 700 строк деревьев и кустарников —
   прогнаны через исходную программу. Наборы охватывают: выплаты и посадки, все
   сочетания К1–К4, причины с заменой коэффициентов, поросль, живую изгородь,
   многоствольные деревья, цветники и газоны в режимах «метрами» и «стоимостью»,
   строки с ошибками. Результаты сохранены в [`tests/vectors`](tests/vectors).
3. Ядро на JavaScript (веб-версия) и на Python (настольная) сверено с этими эталонами:
   **32 816 значений, 0 расхождений**. Исключение — 28 итоговых ячеек набора с ошибками
   ввода, где оригинал выдаёт `#ЗНАЧ!`.
4. Книга Excel заполнена теми же наборами, пересчитана LibreOffice и сверена с ядром:
   **23 697 значений, 0 расхождений**.

```bash
node tests/test_engine.js         # ядро JS против эталонов оригинала
python3 tests/test_engine_py.py   # ядро Python против эталонов оригинала
python3 tests/test_excel.py       # книга Excel против ядра (нужен LibreOffice)
```

## Особенности оригинала, сохранённые без изменений

Расчёт намеренно повторяет оригинал один в один. Ниже — места, которые выглядят как
ошибки исходной программы. Они перенесены как есть, чтобы цифры совпадали.
Проверьте их по действующему нормативному акту. Примеры посчитаны с К2 = 0,5.

1. **Поросль в итоге считается дважды.** Удаление 20 м² поросли деревьев:
   20 × 0,2 × 0,5 = 2 б.в. В «ИТОГО всех выплат» получается 4 б.в. Поросль входит и в
   строку «уч-ки поросли», и в «в т.ч. за лиственные декоративные» через тип «поросль →
   быст.». То же относится к поросли кустарников.
2. **Участок меньше 10 м²** считается как площадь × 2 б.в. В итоге 5 м² дают 5 б.в.,
   а 10 м² — только 1 б.в. (до удвоения из пункта 1). Нормы «менее 10 м²» в
   справочниках равны нормам «за 10 м²». Это наводит на мысль, что задумывалась
   фиксированная сумма.
3. **Коэффициент 0,1 для поросли «у дорог»** виден в строке, но не попадает в итоговый
   расчёт поросли.
4. **Масса кустарника (т)** считается только для строк с количеством ровно 1. Строка
   «Барбарис, 5 шт.» даёт 0 т, «Барбарис, 1 шт.» — 0,012 т.

Исправить любой из пунктов — это правка в одном месте ядра и в формулах Excel.

## Отличия от оригинала

* Нет проверки лицензии, макросов и защиты листов.
* Ошибка в одной строке (не указана причина, неверный диаметр, порода не найдена) не
  превращает все итоги в `#ЗНАЧ!`. Строка помечается, итоги считаются без неё, а число
  ошибок показано вверху.
* Пустые строки внутри ведомости допустимы. В оригинале первая пустая строка
  заканчивала таблицу.
* Порода выбирается из всей библиотеки, без отдельного «рабочего списка».
* Дробный диаметр, введённый числом (например 12.5), считается одним стволом.
  В оригинале «12,5» распадалось на два ствола, 12 и 5.

## Сборка и разработка

```
core/engine.js         ядро расчёта (браузер и Node.js)
core/engine.py         то же на Python (настольная программа, тесты Excel)
core/reference.json    справочники из оригинала
core/reports.py, importer.py, xlsx_io.py   ведомости, импорт .xlsm, запись .xlsx (Python)
web/src/               исходники веб-версии; tools/build_web.py собирает web/taksaciya.html
desktop/               настольная программа (Tkinter) и build_exe.bat
tools/build_excel.py   генерирует excel/Таксация-Лайт.xlsx
tests/                 эталоны оригинала и сравнение
```

* Веб-версия: `python3 tools/build_web.py`.
* Excel: `python3 tools/build_excel.py --rows 2000` (нужен openpyxl).
* `TaksaciyaLite.exe`: GitHub Actions, сценарий `.github/workflows/taksaciya.yml`,
  собирает его на Windows при каждом изменении папки `taksaciya/`. Перед сборкой
  прогоняются тесты, после — самопроверка exe. Готовый комплект (exe, веб-версия,
  книга Excel) лежит в артефакте `Taksaciya-Lite-Windows`. Собрать вручную на Windows:
  `desktop\build_exe.bat`.

## Важно

Таксация Лайт — независимая программа. Код написан заново, со сторонним продуктом и его
автором она не связана. Справочные значения взяты из файла пользователя. Перед выпуском
проектной документации сверяйте тарифы, коэффициенты и базовую величину с действующими
нормативными правовыми актами Республики Беларусь.
