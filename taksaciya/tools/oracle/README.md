# Эталоны из оригинальной программы

Скрипты, которыми получены `tests/vectors/*.json`. Нужен сам файл «ТАКСАЦИЯ-АВТО 4.2» (.xlsm),
Python 3 с `lxml` и LibreOffice. В репозиторий оригинал не входит.

```bash
export TAKS_ORACLE_WORK=/tmp/oracle_work
python3 prepare.py /путь/к/ТАКСАЦИЯ-АВТО.xlsm
python3 gen.py            # все наборы; или: python3 gen.py c02_money_mix
```

`prepare.py` убирает из копии оригинала только пустые отформатированные строки скрытого листа
«УДд» и делает две правки совместимости с LibreOffice, не меняющие логику:
имя листа `Библ.ОРМ` берётся в кавычки, а `MATCH(J:J,…)` (неявное пересечение Excel) заменяется на
`MATCH(J<строка>,…)`. После этих правок LibreOffice (локаль ru-RU) совпадает с сохранёнными
значениями Excel во всех ячейках исходного файла (`cmpvals.py`).

`gen.py` вписывает случайные данные в ведомость «СУЩд», настройки, причины, цветники и газоны,
отмечает используемые породы в рабочем списке «Библ.ОРМ», пересчитывает книгу и сохраняет
значения ячеек.
