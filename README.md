# Печати и подписи 3.0 — portable для Windows

[**Скачать StampExtractor-Portable-3.0.0.exe**](https://github.com/Sh0MeM0/Games/blob/stamp-extractor/downloads/StampExtractor-Portable-3.0.0.exe)

Откройте ссылку и нажмите **Download raw file**. Запустите скачанный `.exe`:
установка, дополнительные программы и интернет для обработки не нужны.
Windows 10/11 x64. ZIP исходников не заменяет готовый EXE — бинарник хранится в Git LFS.

Программа ищет печати и подписи на скриншоте, скане или фотографии, удаляет фон
и сохраняет объекты отдельными PNG на белом фоне. Русское и английское
распознавание текста работает локально.

В версии 3.0 переработаны поиск наклонных прямоугольных печатей и отделение
печатных фрагментов от подписей. У печати есть режимы **Рамка и печатный текст**
и **Всё внутри рамки**. Короткие разрывы можно соединять по направлению видимых
штрихов: такие добавления подсвечиваются в предпросмотре и обозначаются суффиксом
`_достроено` в имени PNG.

Достроенные участки — предположение, а не восстановленные пиксели исходника.
Одноцветные пересечения подписи, текста и печати не всегда можно разделить
автоматически. Проверьте результат кнопками **Показать оригинал** и
**Подсветить достроенные участки**; достройку можно отключить.

Другие проекты в репозитории находятся в отдельных ветках; эта ветка — `stamp-extractor`.
