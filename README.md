# PDF Мастер 0.1.0 — Установщик, Windows 10/11 x64

Готовая автономная программа для PDF → DWG / DXF / DOCX с русским интерфейсом,
редактируемым текстом и векторной геометрией, OCR русского и английского текста.
AutoCAD, ODA, Python и интернет для конвертации не требуются.

## Скачать и запустить

1. [Скачайте ZIP этой ветки](https://github.com/Sh0MeM0/Games/archive/refs/heads/pdfmaster-installer-v0.1.0.zip) или нажмите **Code → Download ZIP**.
2. Распакуйте скачанный ZIP **целиком** в обычную папку Windows.
3. Дважды нажмите **`RESTORE.cmd`**. Он соберёт `PDFMaster-Setup-x64.exe` из частей и проверит SHA-256. Права администратора и скачивание дополнительных программ не нужны.
4. После сообщения **SUCCESS** запустите `PDFMaster-Setup-x64.exe` для установки.

Файл разделён только из-за ограничения GitHub: в Git нельзя загрузить один файл больше 100 МБ.
Это готовая проверенная сборка; компилировать программу не требуется.
Не запускайте части `.partNN` по отдельности и не запускайте `RESTORE.cmd` прямо внутри ZIP.
Сборка не заменяет уже существующий файл с другим содержимым. При ошибке прочитайте сообщение в оставшемся открытым окне.

## Проверка целостности

Исходный файл: `PDFMaster-Setup-x64.exe`. Размер: 154353744 байт.

SHA-256: `115d89ad9b2ccb6129cb4aa48a15704637dc8fa1689908da76fdb4599b4d37e2`.

`manifest.json` содержит размеры и SHA-256 всех частей. `SHA256SUMS.txt` — контрольные суммы всех оригинальных дистрибутивов версии.
Готовый файл после сборки побайтно совпадает с проверенным дистрибутивом.

## Исходники и ограничения

Полный код приложения, тесты, сценарий сборки и лицензии включены в `PDFMaster-Source.zip`.
[Исходники в GitHub](https://github.com/Sh0MeM0/Games/tree/pdfmaster-v0.1.0).
В программе есть Liberation и osifont и поддержка собственных шрифтов; все существующие шрифты не включены.
Для сканов восстановление геометрии приблизительное. Пройдено 87 тестов и проверки под Wine.
Нативная Windows, AutoCAD и Microsoft Word не проверены. EXE не подписан Authenticode.
