# PDF Мастер 0.1.1 — portable для Windows 10/11 x64

[Скачать полный архив portable](https://github.com/Sh0MeM0/Games/archive/refs/heads/pdfmaster-portable-v0.1.1.zip).

## Запуск

1. Скачайте ZIP по ссылке выше или через **Code → Download ZIP**.
2. Распакуйте скачанный архив **целиком** в обычную папку Windows.
3. Запустите **RESTORE.cmd**. Он восстановит `PDFMaster-Portable-x64.zip` из частей и проверит SHA-256.
4. После сообщения **SUCCESS** распакуйте восстановленный ZIP в **новую папку** и откройте `PDFMaster.exe`.
5. Повторно преобразуйте исходные PDF в DWG: ранее созданные чертежи автоматически не исправляются.

Установка программы, Python, AutoCAD или ODA для конвертации не требуется.
Части нужны из-за лимита GitHub в 100 МБ на один файл; компилировать программу не нужно.
`RESTORE.cmd` не заменяет отличающийся существующий файл, а создаёт имя с `(2)`.
Не запускайте скрипт внутри нераспакованного ZIP и не открывайте отдельные `.partNN`.

## Что исправлено

- Устранено обнуление высоты и ошибочная ширина MTEXT при записи DWG в LibreDWG 0.14.
- Текст сохраняется редактируемыми объектами TEXT с исходными базовыми линиями и длиной строк; высота определяется по метрикам шрифта.
- На проверочном документе сохранены все 97 текстовых фрагментов и их размещение в таблице.
- Убран предел 180 секунд для DWG и OCR. Обработка идёт до завершения или нажатия «Остановить».
- Длительная работа сопровождается сообщением каждые 30 секунд; отмена останавливает внешний конвертер.

Полный набор: **106 тестов прошли**. Windows runtime проверен под Wine, включая реальный запуск 185 секунд, отмену и конвертацию PDF/сканов.
Проверка в нативной Windows и непосредственно в AutoCAD/Word не выполнялась. EXE не подписаны Authenticode.
