# PDF Мастер 0.2.0 — portable для Windows 10/11 x64

[Скачать полный архив portable](https://github.com/Sh0MeM0/Games/archive/refs/heads/pdfmaster-portable-v0.2.0.zip).

## Запуск

1. Скачайте ZIP по ссылке выше или через **Code → Download ZIP**.
2. Распакуйте скачанный архив **целиком** в обычную папку Windows.
3. Запустите **RESTORE.cmd**. Он соберёт `PDFMaster-Portable-x64.zip` из частей и проверит SHA-256.
4. После сообщения **SUCCESS** распакуйте полученный ZIP в **новую папку** и откройте **PDFMaster.exe**.

Python, AutoCAD, ODA и OCR отдельно устанавливать не нужно. Конвертация работает локально.
Части нужны из-за ограничения GitHub в 100 МБ на файл; компилировать программу не требуется.
Не запускайте `RESTORE.cmd` внутри нераспакованного ZIP и не открывайте отдельные `.partNN`.
Скрипт сохраняет существующие отличающиеся файлы, выбирая имя с `(2)`.

## Новое в 0.2.0

- TIF/TIFF, включая многостраничные файлы, преобразуются в DWG, DXF и DOCX.
- Добавлены очистка фона и изолированного шума, выравнивание без обрезки, DPI из файла или вручную.
- Линии и кривые скана восстанавливаются редактируемыми линиями и полилиниями; OCR-текст сохраняется в TEXT.
- Включены более точные модели OCR русского и английского `tessdata_best`; добавлен отсев крупных ложных надписей, образованных пересечениями линий.
- Добавлены 40 файлов шрифтов: всего 54 файла, 18 семейств с кириллицей и техническими символами.
- Ускорена запись больших DWG: исправлены повторные обходы DXF и ссылок в LibreDWG.
- Общее время DWG/OCR не ограничивается; есть сообщения о работе и кнопка «Остановить».

Сканы восстанавливаются приблизительно. Рукописные и повреждённые слова, цифры,
тонкие условные знаки и остатки шума требуют проверки. Исходные файлы не изменяются.
Очищенная подложка сохраняется рядом с DWG: переносите папку `document_…_images`
вместе с чертежом. Её слой можно включить в CAD для сверки.
Для отображения текста в CAD установите используемые шрифты из `assets/fonts`
или добавьте их в каталог поиска CAD. Комплект не является сертификацией ГОСТ.

[Инструкция и ограничения](https://github.com/Sh0MeM0/Games/blob/pdfmaster-v0.2.0/README.md).
[Выполненные проверки](https://github.com/Sh0MeM0/Games/blob/pdfmaster-v0.2.0/docs/VALIDATION.md).
Windows runtime проверен под Wine; нативные Windows, AutoCAD и Word в среде проверки отсутствуют.
EXE не подписаны Authenticode.

## Целостность и исходники

Размер portable ZIP: 273086407 байт.

SHA-256: `40d8317ec4026c13a9f0f129e228e3926323eb9c2c304c28ed0f0de1afc8de52`.

Контрольные суммы частей — в `manifest.json`, portable и исходников — в `SHA256SUMS.txt`.
Исходный код, тесты и инструкции сборки входят в `PDFMaster-Source.zip`.
[Код версии 0.2.0](https://github.com/Sh0MeM0/Games/tree/pdfmaster-v0.2.0).

Выпускается только portable. Частные пользовательские документы и их результаты в архив не включены.
