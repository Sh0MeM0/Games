# Импульс — Android-игра

[Скачать APK](https://github.com/Sh0MeM0/Games/raw/refs/heads/apk-download/impulse-1.0.apk)

Тестовая подписанная сборка 1.0.0 для Android 7 и новее. Работает без интернета.

Нажимайте центральную кнопку, покупайте 384 улучшения в 24 ветках, развивайте сеть из 12 дополнительных кнопок. Есть автоматические нажатия, комбо, критические нажатия, турборежим, заработок вне игры, престиж, 24 достижения и сохранение прогресса.

## Установка

1. Скачайте `impulse-1.0.apk` на Android-телефон.
2. Откройте скачанный файл. Если Android попросит, разрешите установку приложений для браузера или файлового менеджера, которым открываете APK.
3. Нажмите «Установить» и откройте «Импульс».

Это тестовая сборка, не релиз Google Play. Проверены механика и интерфейс; установка, нажатия, навигация и восстановление прогресса проверены на эмуляторе Android 11. Проверка на Android 15 не завершена из-за сбоя системного WebView эмулятора.

SHA-256 приведён в `impulse-1.0.apk.sha256`.
