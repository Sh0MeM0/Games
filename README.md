# PDF Мастер 0.3.0 — portable для Windows 10/11 x64

[Скачать полный архив portable](https://github.com/Sh0MeM0/Games/archive/refs/heads/pdfmaster-portable-v0.3.0.zip).

## Запуск

1. Скачайте ZIP по ссылке выше или через **Code → Download ZIP**.
2. Распакуйте скачанный архив **целиком** в обычную папку Windows.
3. Запустите **RESTORE.cmd**. Он соберёт `PDFMaster-Portable-x64.zip` из частей и проверит SHA-256.
4. После сообщения **SUCCESS** распакуйте полученный ZIP в **новую папку** и откройте **PDFMaster.exe**.

Python, AutoCAD, ODA и OCR отдельно устанавливать не нужно. Конвертация работает локально.
Части нужны из-за ограничения GitHub в 100 МБ на файл; компилировать программу не требуется.
Не запускайте `RESTORE.cmd` внутри нераспакованного ZIP и не открывайте отдельные `.partNN`.
Скрипт сохраняет существующие отличающиеся файлы, выбирая имя с `(2)`.

## Новое в 0.3.0

- JPG/JPEG, PNG/APNG, BMP/DIB, WebP, GIF, AVIF, JPEG 2000, PCX, TGA и PPM/PGM/PBM/PNM преобразуются в DWG, DXF и DOCX; PDF/TIFF сохранены.
- Для изображений доступны очистка фона/шума, выравнивание, OCR и редактируемые линии/полилинии.
- Исправлена потеря светлой тонкой штриховки рядом с чёрными контурами и разрывы штрихов после очистки JPEG.
- Учитываются EXIF-поворот, прозрачность, CMYK, DPI по обеим осям и выбор кадров анимации.
- При неверном расширении поддерживаемое изображение читается по фактическому формату с предупреждением.
- Подложка векторизированного изображения выключается, чтобы показать редактируемую геометрию; её можно включить для сверки.
- В комплекте 54 файла шрифтов, OCR русского и английского и ускоренный конвертер DWG без лимита 180 секунд.

Сканы восстанавливаются приблизительно. Рукописные и повреждённые слова, цифры,
тонкие условные знаки и остатки шума требуют проверки. Если в картинке нет физического DPI, используется 300 DPI с предупреждением; масштаб CAD нужно проверить по известному размеру. Фотографическая перспектива автоматически не исправляется. Исходные файлы не изменяются.
Очищенная подложка сохраняется рядом с DWG: переносите папку `document_…_images`
вместе с чертежом. Её слой можно включить в CAD для сверки.
Для отображения текста в CAD установите используемые шрифты из `assets/fonts`
или добавьте их в каталог поиска CAD. Комплект не является сертификацией ГОСТ.

[Инструкция и ограничения](https://github.com/Sh0MeM0/Games/blob/pdfmaster-v0.3.0/README.md).
[Выполненные проверки](https://github.com/Sh0MeM0/Games/blob/pdfmaster-v0.3.0/docs/VALIDATION.md).
Windows runtime проверен под Wine; нативные Windows, AutoCAD и Word в среде проверки отсутствуют.
EXE не подписаны Authenticode.

## Целостность и исходники

Контрольные суммы частей — в `manifest.json`, portable и исходников — в `SHA256SUMS.txt`.
