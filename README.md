# Печати и подписи 2.0 — portable для Windows

[**Скачать StampExtractor-Portable-2.0.0.exe**](https://github.com/Sh0MeM0/Games/blob/stamp-extractor/downloads/StampExtractor-Portable-2.0.0.exe)

Откройте ссылку и нажмите **Download raw file**. Запустите скачанный `.exe`:
установка, дополнительные программы и интернет для обработки не нужны.
Windows 10/11 x64. ZIP исходников не заменяет готовый EXE — бинарник хранится в Git LFS.

Программа автоматически распознаёт русский/английский печатный текст, выделяет
печати и подписи, очищает фон и сохраняет каждый объект отдельным PNG на белом фоне.
В версии 2.0 добавлено настоящее офлайн-распознавание текста вместо прежнего
объединения групп штрихов. Надписи обнаруженных печатей сохраняются.

![Новая версия на документе с текстом, двумя печатями и двумя подписями](stamp-extractor/examples/interface.png)

Сильное размытие и перекрывающиеся одноцветные штрихи нельзя надёжно восстановить
из одного снимка. Для таких случаев оставлены ручная корректировка и сравнение
с оригиналом. Программа не дорисовывает скрытые детали.

Другие проекты в репозитории находятся в отдельных ветках; эта ветка — `stamp-extractor`.
