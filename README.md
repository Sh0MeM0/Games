# PC Monitor Tool 1.1.0

PC Monitor Tool показывает, сколько времени пользователь провёл в приложениях Windows 10/11. Сеанс начинается кнопкой «Начать сеанс» после подтверждения. На вкладке «Обзор» отображается время по приложениям за сегодня.

## Сборка и установка

Для запуска нужна Windows 10 x64 версии 1809 или новее либо Windows 11 x64. Для сборки нужен .NET 8 SDK. Откройте PowerShell в каталоге с `PCMonitorTool.sln` и выполните:

```powershell
dotnet publish .\src\PCMonitorTool\PCMonitorTool.csproj -c Release -r win-x64 --self-contained true -o .\publish\win-x64
.\publish\win-x64\pcmtool.exe
```

Если вы скачали готовый архив для Windows x64, распакуйте его целиком в отдельную постоянную папку и запустите `pcmtool.exe`. Среда выполнения уже входит в автономную сборку. Программа рассчитана на запуск от имени обычного интерактивного пользователя. Установите её отдельно для каждой учётной записи, в которой пользователь согласился на учёт.

Чтобы обновить уже распакованную программу до версии 1.1.0, нажмите «Выход» в запущенной копии и дождитесь закрытия окна. Распакуйте новый архив целиком в ту же папку с заменой файлов и запустите `pcmtool.exe`.

## Как пользоваться

1. При первом запуске прочтите уведомление. В «Настройках» выберите папку хранения и интервалы. Для смены параметров завершите текущий сеанс.
2. Нажмите «Начать сеанс» и подтвердите перечень данных. Для периодических снимков сначала включите «Предлагать периодические снимки в начале сеанса» в настройках. При каждом новом сеансе отдельно подтвердите автоснимки и укажите в системном окне выбора Windows каждый экран или окно, снимки которого хотите сохранять. После каждого выбора нажмите «Выбрать ещё» для добавления следующего источника или «Готово» для запуска таймера. Windows показывает рамку вокруг выбранного источника на протяжении захвата.
3. Во время учёта **крестик (×) главного окна и «Свернуть» (—) сворачивают его на панель задач**. Учёт времени и разрешённые автоснимки продолжаются. У программы одно главное окно. Активный сеанс обозначается красной меткой на кнопке программы в панели задач. Наведите указатель на кнопку программы и нажмите «Остановить сеанс» в её миниатюре, чтобы завершить сбор. Отдельной плавающей панели и значка рядом с часами нет.
4. Для возврата нажмите кнопку PC Monitor Tool на панели задач, используйте `Ctrl+Alt+Shift+F9` или снова запустите `pcmtool.exe`. Нажмите «Остановить сеанс», чтобы завершить сбор и оставить окно открытым. Кнопка **«Выход»** завершает программу, в том числе во время учёта. При остановленном учёте крестик также закрывает программу. Блокировка, отключение сеанса Windows и переход в сон завершают сеанс учёта. После возвращения запустите новый сеанс вручную.
5. На вкладке «Скриншоты» кнопка «Сделать скриншот сейчас» после подтверждения сохраняет отдельный PNG для каждого подключённого экрана. Там же доступно превью. «Экспорт в ZIP» сохраняет журналы и снимки в выбранный файл за пределами папки данных. Получившийся ZIP может содержать личную информацию.

## Что попадает в учёт

| Раздел | Сохраняемые данные |
| --- | --- |
| Обзор и приложения | Имя исполняемого файла процесса текущего пользователя, PID, время наблюдения. Опрос по умолчанию раз в 30 секунд. Интервал относится к приложению, активному в его начале. После пяти минут без ввода наступает простой. Блокировка и длительные разрывы между измерениями исключаются. Короткие переключения между опросами могут быть пропущены. |
| Запуск и завершение программ | WMI-события `Win32_ProcessStartTrace` и `Win32_ProcessStopTrace`, отфильтрованные по сеансу и SID. При ограничениях WMI панель показывает сообщение. Учёт времени переднего окна продолжает работать. |
| USB | Подключение и отключение готовых съёмных USB-томов с буквой диска. События WMI дополняет сверка раз в минуту. Отдельная настройка включает события создания, изменения, переименования и удаления. Для файлов сохраняются имя и доступный размер. |
| Клики | Время, кнопка и координаты щелчка внутри подписанной тестовой площадки на вкладке «Клики». Координаты заданы относительно площадки в единицах WPF. |
| Скриншоты | Для автоматических снимков нужны Windows 10 версии 1903 или новее либо Windows 11 и поддержка Windows Graphics Capture. По умолчанию автоснимки выключены, интервал 5 минут. Программа периодически сохраняет PNG только для источников, выбранных пользователем в системном диалоге этого сеанса. Системная рамка захвата остаётся видимой и при свёрнутой панели программы. Для снимка рабочего стола выберите весь экран. Если Windows не выдаёт свежего кадра, например у свёрнутого выбранного окна, программа пропускает этот интервал. Защищённое содержимое может быть недоступно для съёмки. Ручной снимок по отдельному подтверждению сохраняет все подключённые экраны. |

Программа не читает историю браузеров, адресную строку, заголовки окон, клавиатурный ввод или буфер обмена. Изменения, которые Windows сообщает через `FileSystemWatcher`, могут повторяться или объединяться. Чтение с флешки и направление копирования по ним определить нельзя. При известных потерях событий в журнал добавляется отметка.

## Где находятся данные

По умолчанию используется `%LOCALAPPDATA%\PCMonitor\`. В настройках можно выбрать отдельную пустую папку или существующее хранилище PC Monitor Tool. Смена папки переключает представление и дальнейшую запись, прежнее хранилище остаётся на месте. Для личных данных используйте папку своего профиля Windows.

- `apps.log`, `files.log` и `clicks.log` создаются при появлении соответствующих событий. Кодировка UTF-8, одна запись JSON на строку. Поля верхнего уровня — `timestamp` и `data`. События учёта времени имеют поля `kind: "foreground"`, `process`, `pid`, `startedUtc`, `endedUtc`, `seconds`.
- Папка `Screenshots\` содержит PNG. В имени `YYYY-MM-DD_HH-mm-ss_monX.png` указаны время и номер источника. При ручном снимке номера начинаются с основного монитора, при периодическом — соответствуют порядку выбора окон и экранов. При совпадении имён добавляется суффикс.
- Журналы делятся на сегменты примерно по 4 МиБ. Совокупная квота журналов и снимков — 1 ГБ (1 000 000 000 байт). При заполнении удаляются старейшие управляемые файлы. Экспортированные за пределы хранилища ZIP-файлы в квоту не входят. Во вкладках отображаются последние 250 записей. Для обзора обрабатываются до 5 000 последних событий приложений, при неполной дневной выборке интерфейс это указывает.
- `appsettings.json` рядом с программой задаёт начальные значения. Пользовательские параметры сохраняются в `%LOCALAPPDATA%\PCMonitor\settings.json`. Архив включает текущие и ротированные журналы и снимки. Служебные файлы и настройки туда не входят.

## Автозапуск, команда Win+R и удаление

На вкладке «Настройки» нажмите «Открыть настройки». Флажок «Открывать панель при входе в Windows» регистрирует программу в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. При входе откроется панель с остановленным учётом.

**Команда `pcmtools`** (с буквой **s** в конце) открывает панель для текущего пользователя Windows. Включите «Открывать панель командой pcmtools в Win+R», нажмите «Сохранить», затем нажмите `Win+R`, введите `pcmtools` и нажмите Enter. Программа использует регистрацию Windows App Paths и при повторном запуске показывает окно уже работающей копии в этом пользовательском сеансе. Основной файл по-прежнему называется `pcmtool.exe`. Для совместимости короткая команда `pcmtool` также работает, если её имя свободно или уже принадлежит программе.

**Если Windows открывает другую копию или в настройках появляется «Команда pcmtool уже зарегистрирована для другого файла».** Для этого пользователя короткое имя указывает на другой путь к исполняемому файлу. Например, могла сохраниться регистрация до переноса папки или адрес другой копии. Завершите запущенную копию кнопкой «Выход», дважды щёлкните по нужному `pcmtool.exe`, включите флажок для `pcmtools` и нажмите «Сохранить». Версия 1.1.0 обновит устаревшую регистрацию. Если `pcmtool` занято другой действующей программой, используйте `pcmtools`. Если занято само имя `pcmtools`, сообщение покажет путь его владельца. Снимите флажок, чтобы сохранить остальные настройки, и используйте полный путь.

**Полный путь для `Win+R`.** В Проводнике, удерживая Shift, нажмите правой кнопкой на нужный `pcmtool.exe` и выберите «Копировать как путь». Нажмите `Win+R`, вставьте полный путь к файлу в двойных кавычках и нажмите Enter. Если сочетание `Ctrl+Alt+Shift+F9` занято, выберите другую функциональную клавишу в настройках.

Перед переносом или удалением выключите оба флажка, сохраните настройки и нажмите «Выход». После этого можно удалить каталог программы. При необходимости удалите отдельно выбранные каталоги данных и свои ZIP-экспорты. Отметка показа первого уведомления хранится в `HKCU\Software\PCMonitorTool\NoticeVersion`.

## Проверка на своём ПК

1. Запустите программу, оставьте сеанс остановленным. Затем начните учёт, поработайте в Блокноте две минуты, откройте «Обзор» и нажмите «Обновить». Проверьте появление времени для `Notepad.exe`.
2. Подключите второй монитор и сделайте ручной снимок. Проверьте оба PNG и их превью. В новом сеансе включите автоснимки и в системном диалоге выберите только одно окно. Убедитесь, что вокруг него видна рамка. Закройте главную панель крестиком во время учёта, дождитесь выбранного интервала и вернитесь через панель задач. Проверьте PNG выбранного окна и состояние «Идёт учёт». После блокировки и разблокировки Windows убедитесь, что учёт остановлен.
3. С включённым журналом USB подключите флешку с буквой диска, создайте тестовый файл и откройте вкладку «Файлы». Проверьте горячую клавишу и команду Win+R, экспортируйте ZIP и откройте его в Проводнике.
4. Для оценки CPU в активном сеансе выключите периодические снимки. Оставьте главное окно открытым, переключитесь в Диспетчер задач и понаблюдайте за `pcmtool.exe` несколько минут. Код использует ожидание событий и таймеры. Целевой показатель 1–2 % требует измерения на конкретной системе.
