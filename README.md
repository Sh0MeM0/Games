# PDF Мастер 0.4.0 — portable для Windows 10/11 x64

[Скачать полный архив portable](https://github.com/Sh0MeM0/Games/archive/refs/heads/pdfmaster-portable-v0.4.0.zip).

## Запуск

1. Скачайте ZIP по ссылке выше или через **Code → Download ZIP**.
2. Распакуйте скачанный архив **целиком** в обычную папку Windows.
3. Запустите **RESTORE.cmd**. Он соберёт `PDFMaster-Portable-x64.zip` из частей и проверит SHA-256.
4. После сообщения **SUCCESS** распакуйте полученный ZIP в **новую папку** и откройте **PDFMaster.exe**.

Python, AutoCAD, ODA, OCR и модели ИИ отдельно устанавливать не нужно. Конвертация,
распознавание и перевод работают локально, без интернета.
Части нужны из-за ограничения GitHub в 100 МБ на файл; компилировать программу не требуется.
Не запускайте `RESTORE.cmd` внутри нераспакованного ZIP и не открывайте отдельные `.partNN`.

## Новое в 0.4.0

- **Нейросетевое распознавание** (PP-OCR в ONNX Runtime, на процессоре): строки под любым
  углом, вертикальные и наклонные надписи чертежей, перекошенные сканы; русский,
  белорусский, украинский, английский. Каждая фраза перепроверяется Tesseract со словарём.
- **Выравнивание по строкам текста** и **исправление перспективы** сфотографированного листа.
- **Ускорение Tesseract**: один поток OpenMP на процесс и параллельные участки.
- **Перекодировка «кракозябр»** в PDF (cp1251/cp1252/UTF-8/KOI8-R/CP866) и OCR вместо
  текста без Unicode-карты.
- **Офлайн-перевод RU↔EN**: отдельные файлы `(EN)`/`(RU)` с сохранением расположения,
  чисел, обозначений осей и кодов.

На шести синтетических сканах полнота распознанных слов выросла с 0,52–0,97 до
0,95–0,98 (таблица — в README и `docs/VALIDATION.md` исходников). Рукописный текст
на реальных рукописях не проверялся. Машинный перевод требует проверки специалистом.

Windows runtime проверен под Wine 9.0 (doctor, распознавание изображений и PDF, DWG,
DOCX, перевод); нативные Windows, AutoCAD и Word в среде проверки отсутствуют.
EXE не подписаны Authenticode.

## Целостность и исходники

Размер portable ZIP: 656324375 байт.

SHA-256: `526298f5b144cb4311e4f260d91713fdf194efe5718aa7fb18fcd39017e0c495`.

Контрольные суммы частей — в `manifest.json`, portable и исходников — в `SHA256SUMS.txt`.
Исходный код, тесты и сценарии сборки входят в `PDFMaster-Source.zip`; модели ИИ
загружаются скриптом `scripts/fetch_models.py` с проверкой SHA-256.
Лицензии моделей — `licenses/models` внутри portable, общие сведения — `THIRD_PARTY_NOTICES.md`.
