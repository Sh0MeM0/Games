# Установщик Windows

`SharedArchive-Setup-1.0.0.exe` — уже собранный установщик NSIS для Windows 10/11 x64.
Файл хранится через Git LFS, а не обычным Git-объектом.

На странице файла в GitHub нажмите **Download raw file**. Для скачивания
через командную строку с установленным Git LFS выполните `git lfs pull`.
Архив исходников GitHub может содержать только указатель вместо `.exe`.

SHA-256 указан в `SHA256SUMS.txt`. Установщик не подписан; установка и удаление
на настоящих Windows, а также интеграция с Word/Excel пока не проверены.
Для подключения приложения отдельно разверните сервер по корневому README.md.
