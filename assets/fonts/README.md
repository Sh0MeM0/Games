# Шрифты

В комплект включены **54 неизменённых файла шрифтов, 18 семейств**:

| Семейства | Начертания / назначение | Лицензия |
|---|---|---|
| Liberation Sans, Serif, Mono | 12 файлов: обычный, полужирный, курсивный, полужирный курсивный | SIL OFL 1.1 |
| osifont | 2 файла: обычный и наклонный технический шрифт | GPL-3 с исключением для встраивания |
| PT Sans, PT Serif | 8 файлов: четыре основных начертания | ParaType Free Font License |
| PT Sans Caption, PT Sans Narrow, PT Mono | 6 файлов: обычный и полужирный; мелкие подписи, узкие строки, моноширинный текст | ParaType Free Font License |
| PT Serif Caption | 2 файла: обычный и курсивный; мелкие подписи | ParaType Free Font License |
| DejaVu Sans, Serif, Sans Mono | 12 файлов: четыре основных начертания; кириллица, греческий, технические знаки | Bitstream Vera; изменения DejaVu — public domain |
| Noto Sans, Noto Serif | 8 файлов: четыре основных начертания; кириллица и греческий | SIL OFL 1.1 |
| Noto Sans Math, Noto Sans Symbols, Noto Sans Symbols2 | 4 файла: математические и специальные знаки; у Symbols также полужирный | SIL OFL 1.1 |

Полные оригинальные уведомления находятся рядом со шрифтами:
`Liberation-LICENSE.txt`, `osifont-LICENSE.txt`, `ParaType-LICENSE.txt`,
`DejaVu-LICENSE.txt` и `Noto-LICENSE.txt`. Файлы TTF не изменялись.
Специализированные Noto Math/Symbols не являются заменой кириллического
шрифта целой страницы: выбирайте их для соответствующих символов.
Добавление шрифтов не распознаёт автоматически гарнитуру, которой был
напечатан скан, и само по себе не исправляет ошибки OCR.

osifont — открытый технический шрифт; программа **не удостоверяет соответствие
ГОСТ 2.304**. Для нормативного оформления укажите папку со своими законно
полученными TTF/OTF-шрифтами и выберите нужное семейство. Локальные шрифты
Windows также доступны. SHX — специальный формат CAD, он не используется для
оформления DOCX. Все существующие коммерческие шрифты не включены.

Шрифты взяты из установленных пакетов Debian `fonts-liberation` и
`fonts-osifont 0.1.20230322+ds-4`. Соответствующий исходный код osifont вместе
с Debian build scripts помещён в `osifont-source/`; исходные архивы и контрольный
файл получены с `https://deb.debian.org/debian/pool/main/f/fonts-osifont/`.
SHA-256 архивов проверены по `.dsc`, полученному по HTTPS.

Дополнительные 40 файлов получены из официальных пакетов Debian:
`fonts-paratype 20181108-4`, `fonts-dejavu-core`, `fonts-dejavu-extra`,
`fonts-dejavu-mono 2.37-8`, `fonts-noto-core 20201225-2`. Подписи Debian
`InRelease` проверены системным ключевым кольцом; SHA-256 индекса `Packages`
сверен с подписанным `InRelease`, SHA-256 пакетов — с этим индексом.
`SOURCES.json` содержит точные URL, версии, исходные пути, контрольные суммы
каждого пакета, TTF и лицензии, а также сведения о проверке репозитория.
Проверить комплект можно из исходного проекта командой
`python scripts/fetch_fonts.py`; восстановить те же дополнительные файлы
по закреплённым контрольным суммам на Linux с `dpkg-deb` —
`python scripts/fetch_fonts.py --restore`. Установка системных пакетов
или изменение системных шрифтов для этого не требуется.

Экспорт сохраняет ссылку на название шрифта, но не встраивает произвольные
проприетарные шрифты. Чтобы документ выглядел одинаково на другом компьютере,
установите там разрешённые лицензией шрифты из этого каталога либо свои аналоги.
Шрифты внутри исходного PDF не извлекаются для обхода ограничений лицензии.
