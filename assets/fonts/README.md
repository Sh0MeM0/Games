# Шрифты

В комплект включены неизменённые Liberation Sans, Serif и Mono (обычный,
полужирный, курсивный и полужирный курсивный; SIL Open Font License 1.1),
а также osifont и osifont italic (GPL-3 с исключением для встраивания шрифта
в документы). Полные уведомления находятся рядом со шрифтами.

osifont — открытый технический шрифт; программа **не удостоверяет соответствие
ГОСТ 2.304**. Для нормативного оформления укажите папку со своими законно
полученными TTF/OTF-шрифтами и выберите нужное семейство. Локальные шрифты
Windows также доступны. SHX — специальный формат CAD, он не используется для
оформления DOCX. Все существующие коммерческие шрифты не включены.

Шрифты взяты из установленных пакетов Debian `fonts-liberation` и
`fonts-osifont 0.1.20230322+ds-4`. Соответствующий исходный код osifont вместе
с Debian build scripts помещён в `osifont-source/`; исходные архивы и контрольный
файл получены с `https://deb.debian.org/debian/pool/main/f/fonts-osifont/`.
SHA-256 архивов проверены по `.dsc`, полученному по HTTPS.

Экспорт сохраняет ссылку на название шрифта, но не встраивает произвольные
проприетарные шрифты. Чтобы документ выглядел одинаково на другом компьютере,
установите там разрешённые лицензией шрифты из этого каталога либо свои аналоги.
Шрифты внутри исходного PDF не извлекаются для обхода ограничений лицензии.
