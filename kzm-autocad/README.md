# Картограмма земляных масс для AutoCAD 2021–2026

Модуль AutoCAD (C#, AutoCAD .NET API): картограмма земляных масс методом квадратов.
Версия **0.5.0**.

Вся работа идёт в **боковой панели «КЗМ»** (команда `KZM`). Командная строка нужна только там,
где указывают объекты мышью или вводят отметку при ручном вводе точек.

## Что нового в 0.5.0

**Понятнее**
- Стартовая страница «Порядок работы»: шаги с отметкой, что уже сделано в чертеже, и кнопками
  следующего действия. Открывается, когда ничего не выбрано, и кнопкой «?».
- Значки в дереве, подсказки при наведении, правый щелчок — все действия с поверхностью
  или картограммой, двойной щелчок — показать на чертеже, Delete — удалить.
- Картограмма: кнопка «Проверить» считает объёмы, не меняя чертёж. Итоги показывают баланс
  (насыпь − выемка), число полных и неполных квадратов, контрольный расчёт и список замечаний;
  двойной щелчок по замечанию показывает место на чертеже.
- «Показать сетку» — временный показ сетки квадратов до построения. Удобно подобрать
  базовую точку и угол.

**Функциональнее** (пункты задания, которых не было в 0.4)
- Структурные линии по полилинии (п. 1, 2.3). Отметки в вершинах берутся из 3D-полилинии,
  из точек поверхности или вводятся; пустые заполняются по длине; можно задать «начало и конец».
- Плоскость по 3 точкам или по точке и двум уклонам в ‰ (п. 2.3). Точки на плоскости ставятся
  указанием или в вершинах полилинии; контур можно сделать структурной линией.
- «Поменять диагональ» в паре треугольников (п. 3).
- Исключение точек из триангуляции (п. 3): исключённые точки серые, их можно вернуть.
- Импорт из POINT с отметкой в Z и из блоков с атрибутом отметки (п. 2.1). Тег атрибута
  выбирается в форме, номер точки можно взять из второго атрибута.
- Контрольный расчёт объёма по наложению поверхностей с расхождением в м³ и % (п. 5).
- Выгрузка в Excel (.xlsx) или CSV: узлы, квадраты, итоги, контрольный расчёт (п. 6).
- При пересчёте подписи, сдвинутые вручную, ставятся на прежнее место (п. 7).
- Шаблон подписей в узле: угол, слой, цвет каждой из трёх подписей (п. 4).
- Шаблон по умолчанию для новых чертежей и картограмм (п. 8).
- Таблица точек: поиск, сортировка по столбцам, сдвиг отметок выбранных точек на Δ.

**Исправлено**
- В 0.4 «Пересчитать» и «Стереть построение» удаляли вставленную ведомость объёмов
  вместе с заполненными вручную строками. Теперь ведомость остаётся, а модуль обновляет
  в ней только строку «Грунт планировки территории».

**Быстрее**
- Треугольники выводятся одним блоком, а не тысячами отрезков: быстрее включаются,
  выключаются и обновляются, чертёж не засоряется.
- Объекты картограммы запоминаются списком, поэтому пересчёт не перебирает весь чертёж.
- Панель обновляется быстрее: каждая поверхность сверяется один раз за обновление,
  а не для каждой картограммы заново.
- Расчёт картограммы идёт в осях сетки. Площади не теряют точность при координатах
  съёмки порядка 5 000 000 м.

## Установка

1. Закройте AutoCAD.
2. Запустите `releases/KZM-Setup-0.5.0.exe`. Если модуль уже стоит, выберите «Исправить / обновить».
   Модуль ставится в `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Kzm.bundle`.
3. Откройте AutoCAD: появятся меню **«Картограмма»** и вкладка ленты **«КЗМ»**.
   Панель открывается командой `KZM`.

Установщик не подписан цифровой подписью, поэтому Windows может показать предупреждение SmartScreen.

| AutoCAD | Платформа сборки | Пакет API |
|---|---|---|
| 2021 / 2022 / 2023 / 2024 | .NET Framework 4.8 | AutoCAD.NET 24.0.0 / 24.1.51000 / 24.2.0 / 24.3.0 |
| 2025 / 2026 | .NET 8 | AutoCAD.NET 25.0.1 / 25.1.0 |

## Порядок работы

```
┌ КЗМ ─────────────────────────────────────────────────────┐
│ + Поверхность │ + Картограмма │ Импорт │ Пересчитать │ … │
├──────────────────────────────────────────────────────────┤
│ ▼ Фактические (1)                                        │
│   ▼ Съёмка — 523 т. (текущая)                             │
│       Точки (523)                                         │
│ ▼ Проектные (1)                                           │
│   ▶ Вертикальная планировка — 48 т., линий 3              │
│ ▼ Картограммы (1)                                         │
│     КЗМ-1  +1250 / −980 м³                                │
├──────────────────────────────────────────────────────────┤
│ свойства выбранного или «Порядок работы»                  │
└──────────────────────────────────────────────────────────┘
```

1. **«+ Поверхность»**: имя, тип (фактическая / проектная) и слой точек.
2. **Точки** (свойства поверхности, раздел «Точки»):
   - «Импорт из текстов…». Источник отметок: тексты (TEXT, MTEXT), POINT с отметкой в Z
     или блоки с атрибутом. Выбор: рамкой, по слоям или «подобные образцу». XY для текстов —
     по маркеру или по точке вставки. Нажмите «Проверить» (чертёж не меняется), затем «Импортировать».
   - «Создать вручную…» (или команда `KZM_POINT`): укажите точку на чертеже (привязки работают),
     введите отметку. Enter — повторить предыдущую отметку, Esc — закончить.
   - «Плоскость…»: по 3 точкам или по точке и уклонам. Точки ставятся указанием
     или в вершинах полилинии.
   - «Таблица точек»: номер и отметка правятся в ячейке; есть поиск, сортировка, «Исключить»
     и «Вернуть», «Сдвинуть отметки на Δ».
3. **Структурные линии** (свойства поверхности): «Добавить по полилинии…».
   - Таблица вершин показывает отметку и откуда она взята. Пустые отметки заполняются
     по длине; можно задать начало и конец.
   - В вершинах без точки поверхности создаются новые точки. Если точка уже есть, она
     становится вершиной линии.
   - Рёбра треугольников идут по линии (на чертеже — красные).
4. **Поверхность (триангуляция)**:
   - внешняя граница — точная маска: снаружи отметок нет, треугольники обрезаются по ней;
   - «Показывать треугольники»;
   - «Поменять диагональ…»: укажите точку у ребра; повторное указание снимает заданную диагональ;
   - «Проверить триангуляцию».
5. **Оформление подписей точек**:
   - шрифт и высота берутся с образца или с импортируемых текстов;
   - цвет отметок и номеров задаётся кнопками;
   - «Применить ко всем точкам» перерисовывает существующие точки.
6. **«+ Картограмма»** — задайте:
   - фактическую и проектную поверхности;
   - границу работ;
   - сетку: шаг, базовую точку (авто или указать), угол, обозначения;
   - масштаб и высоты текста;
   - подписи в узле;
   - контрольный расчёт.

   Кнопки:
   - «Показать сетку» — временный предпросмотр;
   - «Проверить» — объёмы и замечания без изменения чертежа;
   - «Построить» / «Пересчитать»;
   - «Ведомость объёмов…»;
   - «В Excel…».

   После изменения точек, линий, границ или параметров картограмма помечается «УСТАРЕЛА».
   Кнопка «Пересчитать» на панели и команда `KZM_UPDATE` пересчитывают все устаревшие картограммы.

## Расчёт

- Hф и Hпр в любой точке — линейная интерполяция по треугольникам своей поверхности
  (TIN Делоне с рёбрами структурных линий). Вне поверхности и вне её границы — «нет данных»,
  без экстраполяции. h = Hпр − Hф.
- Структурные линии встраиваются в триангуляцию перестановкой рёбер по алгоритму
  S. W. Sloan (Computers & Structures, 1993, т. 47, № 3, с. 441–450).
  - После этого все остальные рёбра снова приводятся к условию Делоне.
  - Отрезок, пересекающий другую структурную линию, пропускается и попадает в замечания:
    отметка на пересечении не определена.
- Квадрат делится на 4 треугольника через центр; h0 = (h1+h2+h3+h4)/4 (задание, п. 5).
- Квадраты, пересечённые границей, обрезаются по границе. Отметки в точках границы, где съёмки
  нет, вычисляются интерполяцией по треугольникам фактической и проектной поверхностей.
- Треугольник со сменой знака h делится точками нулевых работ (линейная интерполяция по ребру).
  Каждая часть считается по формуле V = S·(h1+h2+h3)/3.
- Итоги по столбцам и по рядам; модуль проверяет, что суммы по столбцам, по рядам и общий итог
  совпадают.
- Контрольный расчёт пересекает границу работ, треугольники обеих поверхностей и их границы.
  На каждом кусочке h линейна, поэтому объём между поверхностями получается точным.
  Расхождение = метод квадратов − контрольный, в м³ и в % от контрольного.
- Баланс = насыпь − выемка: «+» — недостаток грунта, «−» — избыток.
- Узел или квадрат без данных поверхности не считается и помечается на слое `КЗМ_ПРОВЕРКА`.

Приёмочные тесты Т1–Т4 и Т6 из задания проверены автоматически на расчётной части.

## Оформление картограммы (СТБ 2073-2010)

| Элемент | Как | Источник |
|---|---|---|
| Сетка квадратов, обозначения столбцов и рядов | слой `КЗМ_СЕТКА` | задание, п. 4; СТБ, п. 7.1 б |
| В узле по умолчанию: рабочая — слева вверху, проектная — справа вверху, фактическая — справа внизу | `КЗМ_ОТМ_РАБ`, `КЗМ_ОТМ_ПРОЕКТ`, `КЗМ_ОТМ_ФАКТ`; угол, слой и цвет меняются | пример Б.4; задание, п. 4 |
| Объём в квадрате «+705» / «-10» | `КЗМ_ОБЪЕМЫ` | пример Б.4; задание, п. 5 |
| Линия нулевых работ — штриховая тонкая | `КЗМ_НУЛ_ЛИНИЯ` (тип DASHED) | СТБ, п. 3.12 |
| Площадь выемок — штриховка под 45° (ANSI31) | `КЗМ_ВЫЕМКА_ШТРИХ` | СТБ, п. 7.1 б |
| Таблица под сеткой: насыпь/выемка по столбцам, «Итого», «Всего» (графы 5 + 20 мм, строки 8 мм) | `КЗМ_ИТОГИ` | СТБ, рис. 8 |
| Итоги по рядам справа | `КЗМ_ИТОГИ` | задание, п. 5 |
| Ведомость объёмов земляных масс | таблица AutoCAD | СТБ, рис. 9 |
| Отметки — 2 знака после запятой, запятая | — | СТБ, п. 3.15 |

Высоты текста по умолчанию (1,8 мм для отметок в узлах, 2,5 мм для объёмов и итогов) взяты из ряда
размеров шрифта ГОСТ 2.304. Конкретных размеров для картограммы СТБ 2073-2010 не задаёт.
Значения видны и меняются в свойствах картограммы.

## Выгрузка (задание, п. 6)

«В Excel…» в свойствах картограммы создаёт `.xlsx` (Office Open XML) или `.csv` — по выбору
в окне сохранения. CSV пишется с разделителем «;», десятичной запятой и в кодировке UTF-8 с BOM:
так его открывает Excel с русскими настройками. В файле три листа:

- **«Узлы»** — номер линии сетки слева направо и сверху вниз, X, Y, Hф, Hпр, h;
- **«Квадраты»** — столбец, ряд, площадь, насыпь, выемка, полный или неполный;
- **«Итоги»** — по столбцам, по рядам, всего, контрольный расчёт и расхождение, баланс,
  параметры и замечания.

Объёмы в файле — с двумя знаками, без округления картограммы.

## Шаблон по умолчанию (задание, п. 8)

Шаблон хранится в файле `%APPDATA%\Sh0MeM0\Kzm\defaults.txt`.

- «Настройки» → «Сохранить как шаблон» — знаки отметок и масштаб.
- Картограмма → «Сделать шаблоном» — шаг, обозначения, масштаб, высоты текста, подписи
  в узле, контрольный расчёт.

Чертёж без своих настроек и каждая новая картограмма берут значения из шаблона. Настройки,
сохранённые в чертеже, важнее шаблона.

## Команды

| Команда | Действие |
|---|---|
| `KZM` | Панель «КЗМ» |
| `KZM_IMPORT` | Панель на форме импорта |
| `KZM_POINT` | Ручной ввод точек в текущую поверхность |
| `KZM_CARTOGRAM` | Новая картограмма |
| `KZM_UPDATE` | Пересчитать устаревшие картограммы |
| `KZM_SETTINGS` | Настройки чертежа |
| `KZM_CLEARMARKS` | Убрать пометки проверки |
| `KZM_MENU`, `KZM_HELP` | Восстановить меню; список команд |

## Сборка

```bash
python3 build.py
```

Нужны .NET SDK 8 (сборка Microsoft, с Windows Desktop SDK), Python 3 и NSIS 3.
Триангуляция, расчёт и запись Excel написаны в модуле: сторонних библиотек нет.

## Ограничения версии 0.5.0

- Работа в AutoCAD и внешний вид панели в среде разработки не проверялись: там нет Windows
  и AutoCAD. Проверены компиляция шести сборок и 131 автоматический тест расчётной части.
  Порядок проверки — `VALIDATION.md`.
- После обновления с 0.4:
  - картограммы на поверхностях с внешней границей будут помечены «УСТАРЕЛА», потому что
    граница теперь обрезает треугольники точно — нажмите «Пересчитать»;
  - треугольники таких поверхностей предложат обновить;
  - знаки точек 0.1–0.3 станут меньше — «Применить ко всем точкам».
- Подписи, сдвинутые вручную в картограмме, построенной версией 0.4, при первом пересчёте
  не сохраняются: модуль начинает их запоминать с построения в 0.5.
