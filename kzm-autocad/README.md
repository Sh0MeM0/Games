# Картограмма земляных масс для AutoCAD 2021–2026

Модуль AutoCAD (C#, AutoCAD .NET API): картограмма земляных масс методом квадратов.
Версия **0.4.0**. Что в ней есть:
- поверхности, построенные триангуляцией (TIN);
- точки — импорт из текстов съёмки или ввод вручную;
- оформление подписей точек: шрифт и высота берутся с образца, цвета отметок и номеров задаются;
- картограмма: граница работ, выбор фактической и проектной поверхностей, сетка, расчёт объёмов;
- оформление картограммы по СТБ 2073-2010;
- ведомость объёмов земляных масс (форма рисунка 9 СТБ 2073-2010).

Вся работа идёт в **боковой панели «КЗМ»**. Командная строка нужна, только чтобы указать объект
мышью и ввести отметку при ручном вводе точек.

## Установка

1. Закройте AutoCAD.
2. Запустите `releases/KZM-Setup-0.4.0.exe`. Если модуль уже стоит, выберите «Исправить / обновить».
   Модуль ставится в `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Kzm.bundle`.
3. Откройте AutoCAD: появятся меню **«Картограмма»** и вкладка ленты **«КЗМ»**.
   Панель открывается командой `KZM`.

Установщик не подписан цифровой подписью, поэтому Windows может показать предупреждение SmartScreen.

| AutoCAD | Платформа сборки | Пакет API |
|---|---|---|
| 2021 / 2022 / 2023 / 2024 | .NET Framework 4.8 | AutoCAD.NET 24.0.0 / 24.1.51000 / 24.2.0 / 24.3.0 |
| 2025 / 2026 | .NET 8 | AutoCAD.NET 25.0.1 / 25.1.0 |

## Порядок работы

```
┌ КЗМ ────────────────────────────────────────────┐
│ + Поверхность │ + Картограмма │ Импорт │ …       │
├─────────────────────────────────────────────────┤
│ ▼ Фактические (1)                               │
│   ▼ Съёмка — 523 т. (текущая)                    │
│       Точки (523)                                │
│ ▼ Проектные (1)                                  │
│   ▶ Вертикальная планировка — 48 т.              │
│ ▼ Картограммы (1)                                │
│     КЗМ-1  +1250 / −980 м³                       │
├─────────────────────────────────────────────────┤
│ свойства выбранного                              │
└─────────────────────────────────────────────────┘
```

1. **«+ Поверхность»**: имя, тип (фактическая / проектная) и слой точек.
2. **Точки** — в свойствах поверхности:
   - «Импорт из текстов…»: тексты рамкой, по слоям или «подобные образцу»; XY по маркеру или
     по точке вставки; «Проверить», затем «Импортировать».
   - «Создать вручную…» (или команда `KZM_POINT`): укажите точку на чертеже (привязки работают),
     введите отметку в командной строке. Enter — повторить предыдущую отметку, Esc — закончить.
3. **Оформление подписей** (в свойствах поверхности):
   - шрифт и высота **берутся автоматически**: при импорте — с выбранных текстов съёмки,
     при ручном вводе — с указанного текста-образца; кнопка «Взять с образца…» делает то же
     в любой момент;
   - цвет отметок и цвет номеров — кнопки с палитрой цветов AutoCAD;
   - «Применить ко всем точкам» перерисовывает существующие точки, «Сохранить для новых» —
     только запоминает оформление для новых.
4. **Номера точек** при импорте:
   - из того же текста («т.15 145,32» → 15);
   - или из соседнего текста-номера («12»): при XY по маркеру — если ближайший к номеру маркер
     принадлежит этой точке; при XY по точке вставки — если номер не дальше 5 высот текста;
   - иначе по порядку.

   В таблице «Точки» номер и отметку можно исправить прямо в ячейке.
5. **Поверхность (триангуляция)** в свойствах поверхности:
   - внешняя граница (замкнутая полилиния) — необязательна;
   - «Показывать треугольники» — рёбра треугольников на слое `КЗМ_ТРЕУГ`;
   - после правки точек средствами модуля треугольники перестраиваются сами;
   - после MOVE/ERASE панель пишет «обновите треугольники».
6. **«+ Картограмма»**:
   - имя;
   - фактическая и проектная поверхности;
   - **граница работ** (замкнутая полилиния);
   - шаг сетки (20 м — задание, п. 4; СТБ 2073-2010, п. 7.2);
   - базовая точка: авто, кратно шагу, или указать;
   - угол: числом или по двум точкам;
   - обозначения столбцов и рядов;
   - масштаб и высоты текста.

   «Построить» — расчёт и вывод на чертёж; повторное нажатие — «Пересчитать».
   После изменения точек, границ или параметров картограмма помечается «УСТАРЕЛА».
   Команда `KZM_UPDATE` пересчитывает все устаревшие картограммы за один раз.
7. **«Ведомость объёмов…»** вставляет таблицу по форме рис. 9 СТБ 2073-2010. Строку «Грунт
   планировки территории» заполняет модуль, остальные строки — вы. Модуль в них ничего не подставляет.

## Расчёт

- Hф и Hпр в любой точке — линейная интерполяция по треугольникам своей поверхности
  (TIN Делоне). Вне поверхности — «нет данных», без экстраполяции. h = Hпр − Hф.
- Квадрат делится на 4 треугольника через центр; h0 = (h1+h2+h3+h4)/4 (задание, п. 5).
- Квадраты, пересечённые границей, обрезаются по границе. Отметки **в точках границы, где съёмки
  нет**, вычисляются интерполяцией по треугольникам фактической и проектной поверхностей.
- Треугольник, где h меняет знак, делится точками нулевых работ (линейная интерполяция по ребру).
  Каждая часть считается по формуле V = S·(h1+h2+h3)/3.
- Итоги по столбцам и по рядам; модуль проверяет, что суммы по столбцам, по рядам и общий итог
  совпадают.
- Узел или квадрат без данных поверхности не считается и помечается на слое `КЗМ_ПРОВЕРКА`.

Приёмочные тесты Т1–Т4 и Т6 из задания проверены автоматически на расчётной части.

## Оформление картограммы (СТБ 2073-2010)

| Элемент | Как | Источник |
|---|---|---|
| Сетка квадратов, обозначения столбцов и рядов | слой `КЗМ_СЕТКА` | задание, п. 4; СТБ, п. 7.1 б |
| В узле: рабочая — слева вверху, проектная — справа вверху, фактическая — справа внизу | `КЗМ_ОТМ_РАБ`, `КЗМ_ОТМ_ПРОЕКТ`, `КЗМ_ОТМ_ФАКТ` | пример Б.4 |
| Объём в квадрате «+705» / «-10» | `КЗМ_ОБЪЕМЫ` | пример Б.4; задание, п. 5 |
| Линия нулевых работ — штриховая тонкая | `КЗМ_НУЛ_ЛИНИЯ` (тип DASHED) | СТБ, п. 3.12 |
| Площадь выемок — штриховка под 45° (ANSI31) | `КЗМ_ВЫЕМКА_ШТРИХ` | СТБ, п. 7.1 б |
| Таблица под сеткой: насыпь/выемка по столбцам, «Итого», «Всего» (графы 5 + 20 мм, строки 8 мм) | `КЗМ_ИТОГИ` | СТБ, рис. 8 |
| Итоги по рядам справа | `КЗМ_ИТОГИ` | задание, п. 5 |
| Ведомость объёмов земляных масс | таблица AutoCAD | СТБ, рис. 9 |
| Отметки — 2 знака после запятой, запятая | — | СТБ, п. 3.15 |

Высоты текста по умолчанию (1,8 мм для отметок в узлах, 2,5 мм для объёмов и итогов) взяты из ряда
размеров шрифта ГОСТ 2.304. Конкретных размеров для картограммы СТБ 2073-2010 не задаёт.
Значения видны и меняются в свойствах картограммы.

## Команды

| Команда | Действие |
|---|---|
| `KZM` | Панель «КЗМ» |
| `KZM_IMPORT` | Панель на форме импорта |
| `KZM_POINT` | Ручной ввод точек в текущую поверхность |
| `KZM_CARTOGRAM` | Новая картограмма |
| `KZM_UPDATE` | Пересчитать устаревшие картограммы |
| `KZM_SETTINGS` | Настройки чертежа |
| `KZM_CLEARMARKS` | Убрать пометки проверки |
| `KZM_MENU`, `KZM_HELP` | Восстановить меню; список команд |

## Сборка

```bash
python3 build.py
```

Нужны .NET SDK 8 (сборка Microsoft, с Windows Desktop SDK), Python 3 и NSIS 3.
Триангуляция и расчёт написаны в модуле: сторонних библиотек нет.

  - «поменять диагональ» и «исключить точку» — этап 2, редактирование;
  - экспорт CSV и контрольный расчёт объёма по наложению поверхностей — этап 6;
  - сохранение ручных смещений подписей при пересчёте — этап 7.

  Нажмите «Применить ко всем точкам» в свойствах поверхности.
