# Картограмма земляных масс для AutoCAD 2021–2026

Модуль AutoCAD (C#, AutoCAD .NET API) для картограммы земляных масс методом квадратов.
Работа идёт поэтапно. Эта версия — **0.2.0, этап 1**:
- панель «КЗМ»;
- поверхности;
- точки-блоки;
- импорт отметок из TEXT/MTEXT с проверкой и отчётом.

Сетки, отметок в узлах, объёмов и таблиц ещё нет — это этапы 4–6.

С версии 0.2.0 вся работа идёт в **боковой панели «КЗМ»**, а не в командной строке.
Командная строка нужна только тогда, когда модуль просит указать объект мышью.

## Установка

1. Закройте все окна AutoCAD.
2. Запустите `releases/KZM-Setup-0.2.0.exe` (нужны права администратора). Если стоит версия 0.1.0,
   выберите «Исправить / обновить».
   Модуль ставится в `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Kzm.bundle`,
   так же как «Профиля».
3. Запустите AutoCAD. Появятся верхнее меню **«Картограмма»** и вкладка ленты **«КЗМ»**.
   Панель открывается пунктом «Панель КЗМ» или командой `KZM`.

Установщик не подписан цифровой подписью, поэтому Windows может показать предупреждение SmartScreen.
Удаление: «Параметры Windows → Приложения» или повторный запуск установщика.
DWG и данные в них при удалении не затрагиваются.

## Панель «КЗМ»

```
┌ КЗМ ─────────────────────────────────────────┐
│ + Поверхность │ Импорт │ Настройки │ …       │
├──────────────────────────────────────────────┤
│ ▼ Фактические (1)                            │
│   ▼ Съёмка 2026 — 523 т. (текущая)           │
│       Точки (523)                            │
│       Близкие точки (2)                      │
│ ▼ Проектные (1)                              │
│   ▶ Вариант 1 — 48 т.                        │
├──────────────────────────────────────────────┤
│ свойства / точки / импорт / настройки        │
└──────────────────────────────────────────────┘
```

Сверху — дерево поверхностей, снизу — то, что выбрано в дереве.
Правый щелчок по поверхности открывает меню: импорт, точки, сделать текущей, свойства.

- **«+ Поверхность»**: имя, тип и слой точек. Сначала задаётся слой, затем в него идут точки.
  По умолчанию предлагаются `КЗМ_ТОЧКИ_ФАКТ` и `КЗМ_ТОЧКИ_ПРОЕКТ`; можно выбрать любой
  существующий слой или ввести новый.
- **Свойства поверхности**: переименовать, сменить тип или слой (с переносом точек на новый слой),
  сделать текущей, удалить вместе с точками.
- **Точки**: таблица X, Y, отметка, источник. Отметка исправляется прямо в таблице.
  Двойной щелчок показывает точку на чертеже. Есть фильтр «только с ошибкой отметки» и кнопка
  удаления выбранных.
- **Близкие точки** (точки ближе допуска 0,01 м): при выборе пары чертёж приближает её и подписывает
  точки «1» и «2». Кнопки: «Оставить 1», «Оставить 2», «Оставить обе», «Удалить обе».
- **Импорт**:
  1. Поверхность.
  2. Тексты: рамкой; по слоям (галочки в списке слоёв с текстами, с количеством);
     подобные образцу (тот же тип, слой, стиль и высота).
  3. XY: по маркеру — указать один образец (POINT, CIRCLE или блок), подобные найдутся сами,
     дальше радиус R; или по точке вставки текста.
  4. Диапазон отметок, шаблон числа, допуск.
  5. **«Проверить»** показывает таблицу, чертёж при этом не меняется:
     - что будет создано, что отброшено и почему, что спорное;
     - отметку можно вписать вручную (жёлтый столбец);
     - «Указать XY» задаёт положение мышью;
     - снятая галочка «Взять» исключает строку из импорта.
  6. **«Импортировать»** создаёт точки, ставит пометки проверки и оставляет проблемные тексты
     выделенными.
- **Настройки**:
  - масштаб;
  - высота подписи и размер знака в мм листа;
  - знаков после запятой;
  - шаблон числа, диапазон, R, допуск;
  - проверка шаблона на примере текста.

Каждое действие панели, меняющее чертёж, выполняется одной командой AutoCAD и отменяется одним `U`.
Указание объектов мышью чертёж не меняет и в журнал отмены не попадает.

## Как устроены данные

- **Точка** — обычный блок `КЗМ_ТОЧКА` (кружок и атрибут `ОТМЕТКА`). Её можно перемещать,
  копировать и удалять обычными командами AutoCAD и ручками.
  Отметку меняют в таблице «Точки», в палитре «Свойства» (Ctrl+1 → Атрибуты → ОТМЕТКА) или
  двойным щелчком по блоку. Точное значение хранится в XData блока.
  Блок вставляется на Z = 0, его Z не используется: перемещение с привязкой к объекту на другой
  высоте не меняет отметку.
- Поверхности, настройки и пары близких точек хранятся в словаре чертежа `SH0MEM0_KZM`
  и сохраняются вместе с DWG.
- Пометки проверки лежат на слое `КЗМ_ПРОВЕРКА` (красный, не печатается).
  Убираются кнопкой «Убрать пометки» или командой `KZM_CLEARMARKS`.

## Правила разбора отметок

- MTEXT очищается от кодов форматирования, в TEXT убираются коды `%%`.
- Берутся все числа по шаблону, затем остаются только числа в диапазоне [min…max]:
  - ровно одно — точка принята;
  - ни одного — текст отброшен с причиной;
  - несколько — точка спорная.
- Запятая и точка равноправны. Знак «−» (U+2212) читается как минус.
- Число можно выделить в своём шаблоне именованной группой `(?<num>…)`.
- Маркер (способ б) ничего не решает молча, в спорные попадают:
  - нет маркера в радиусе R;
  - два ближайших маркера отличаются по расстоянию не больше чем на допуск совпадения;
  - один маркер ближайший сразу к нескольким отметкам.
- Точки ближе допуска не отбрасываются: обе создаются, решение принимаете вы.
- Повторный импорт того же текста в ту же поверхность пропускается.

## Настройки и откуда значения

| Параметр | По умолчанию | Откуда |
|---|---|---|
| Шаблон числа | `[-+]?[0-9]+(?:[.,][0-9]+)?` | предложен и согласован на этапе вопросов |
| Диапазон отметок min…max | пусто | задаёте вы |
| Радиус поиска маркера R | пусто | задаёте вы |
| Допуск совпадения точек | 0,01 м | задание, п. 2.1 |
| Масштаб 1:500 / 1:1000 / 1:2000 | пусто | задаёте вы |
| Высота подписи, размер знака (мм листа) | пусто | задаёте вы |
| Знаков после запятой | 2 | задание, п. 4; СТБ 2073-2010, п. 3.15 |

## Команды

| Команда | Действие |
|---|---|
| `KZM` | Открыть панель «КЗМ» |
| `KZM_IMPORT` | Открыть панель на форме импорта |
| `KZM_SETTINGS` | Открыть панель на настройках |
| `KZM_CLEARMARKS` | Удалить пометки проверки |
| `KZM_MENU` | Восстановить меню и вкладку ленты |
| `KZM_HELP` | Список команд |

`KZM_RUN` и `KZM_PICK` — служебные команды панели, вручную их вводить не нужно.

## Сборка из исходников

Нужны .NET SDK 8 (сборка Microsoft, с Windows Desktop SDK), Python 3 и NSIS 3.

```bash
python3 build.py
```

Скрипт прогоняет тесты, собирает шесть сборок и создаёт `releases/KZM-Setup-<версия>.exe`.

## Ограничения этой версии

- Работа в AutoCAD и внешний вид панели в среде разработки не проверялись: там нет Windows и AutoCAD.
  Проверены компиляция шести сборок и автоматические тесты расчётной части.
  Порядок проверки — `VALIDATION.md`.
- Внешний вид не сверялся с nanoCAD GeoniCS: его окна у меня нет.
  Пришлите скриншот — подгоню компоновку.
- POINT с Z и блоки с атрибутом как источники отметки, ручная расстановка точек и триангуляция —
  этап 2.
