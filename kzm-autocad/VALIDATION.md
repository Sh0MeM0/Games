# Проверка версии 0.5.0

## Что проверено автоматически (Linux, без AutoCAD)

- **Сборка.** Шесть сборок (AutoCAD 2021–2026) компилируются без ошибок.
- **131 тест расчётной части**, в том числе:
  - **Т1–Т4, Т6** из задания (как в 0.4);
  - **Т5:** «145,32» = «145.32»; MTEXT с форматированием; «12» отбрасывается с причиной;
  - **структурные линии:**
    - ребро-ограничение появляется в триангуляции;
    - вдоль линии отметка меняется линейно по длине;
    - на случайных наборах до 3000 точек все остальные рёбра удовлетворяют условию Делоне;
    - отрезок через точку делится на два;
    - пересекающиеся линии попадают в замечания;
    - контур площадки сохраняет плоскость точной;
  - **внешняя граница — точная маска:** внутри — интерполяция, на границе — значение, снаружи — «нет данных»;
  - **плоскость:**
    - по 3 точкам (в координатах ~5 000 000 м);
    - по точке и уклонам 15 ‰ / −5 ‰ под 30°;
    - отказ для точек на одной прямой и для уклона > 1000 ‰;
  - **контрольный расчёт:**
    - две плоскости → ровно 400 м³;
    - на неровных поверхностях совпадает с численным интегралом (шаг 0,25 м) в пределах 0,5 %;
    - метод квадратов с шагом 1 м — в пределах 1 %;
    - граница поверхности уменьшает площадь с данными;
  - **Excel:** файл .xlsx — корректный пакет (все части — правильный XML); тот же файл открыт
    сторонней библиотекой openpyxl: листы «Узлы», «Квадраты», «Итоги», в итогах 400 м³;
  - **CSV:** UTF-8 с BOM, «;», десятичная запятая;
  - **записи в чертеже:**
    - шаблон подписей, контрольный расчёт, структурные линии и шаблон по умолчанию
      записываются и читаются без потерь;
    - картограммы 0.4 без изменений не помечаются устаревшими;
  - **числа шагов 6 и 10 ниже** проверены тестами на тех же координатах.

**Не проверено:** работа в AutoCAD и внешний вид панели. Проверьте по шагам ниже, начиная
с AutoCAD 2022.

## Проверка в AutoCAD

### 1. Установка и стартовая страница
1. Запустите `KZM-Setup-0.5.0.exe` при закрытом AutoCAD («Исправить / обновить», если стоит 0.4).
2. Откройте AutoCAD → `KZM`.
3. **Ожидается:**
   - панель с деревом и значками;
   - ниже — «Порядок работы»: шаги 1–4 с красными кружками «○» (ничего не сделано)
     и кнопками «Создать…».

### 2. Тестовые данные
`APPLOAD` → `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Kzm.bundle\Examples\kzm-test-data.lsp`.
Команды:
- `KZM_TEST_DATA` — тексты для импорта;
- `KZM_TEST_CARTO` — данные для картограммы;
- `KZM_TEST_SOURCES` — POINT с отметкой Z и блоки с атрибутами.

### 3. Импорт текстов (как в 0.4)
1. Новый чертёж → `KZM_TEST_DATA`.
2. «+ Поверхность»: «Факт тест», фактическая.
3. «Импорт» → «Тексты», «По слоям» `KZM_TEST_ELEV`, XY «По маркеру», образец — POINT → «Проверить».
4. **Ожидается:**
   - будет создано 4 точки;
   - «12» — отброшено;
   - спорных 4.
5. «Импортировать».
6. **Ожидается:**
   - шрифт и высота подписей точек — как у текстов;
   - на стартовой странице шаг 1 — зелёная «✓».

### 4. Таблица точек, исключение, сдвиг
1. Дерево → «Точки».
2. В поле «Поиск» введите `145,3`.
3. **Ожидается:** остаются точки с отметками 145,3x.
4. Щёлкните заголовок «Отметка».
5. **Ожидается:** сортировка по числу, а не по тексту.
6. Выберите точку → «Исключить».
7. **Ожидается:**
   - точка на чертеже серая;
   - в таблице отмечено «Искл.»;
   - в дереве «искл. 1».
8. «Вернуть».
9. **Ожидается:** обычный цвет.
10. Выберите две точки, в поле «Сдвинуть отметки на» оставьте `0,10` → нажмите кнопку → «Да».
11. **Ожидается:** отметки выросли на 0,10.
12. Нажмите `U`.
13. **Ожидается:** сдвиг отменён целиком.

### 5. Треугольники, диагональ, структурная линия
1. Свойства поверхности → «Показывать треугольники».
2. **Ожидается:**
   - на слое `КЗМ_ТРЕУГ` один блок — щелчок по ребру выделяет все треугольники сразу;
   - привязки к вершинам работают.
3. «Поменять диагональ…» → укажите точку внутри треугольника рядом с внутренним ребром → Esc.
4. **Ожидается:**
   - ребро заменено другой диагональью четырёхугольника (красная);
   - в списке «Структурные линии» — «↔ Диагональ …».
5. «Поменять диагональ…» → укажите точку у красной диагонали.
6. **Ожидается:** «заданная ранее диагональ снята».
7. Нарисуйте полилинию через две-три точки поверхности и пустое место → «Добавить по полилинии…» → укажите её.
8. **Ожидается:**
   - таблица вершин: у вершин в точках — «точка поверхности т.N», пустые — красные;
   - «Заполнить пустые по длине» заполняет промежуточные;
   - «Создать структурную линию» создаёт точки в пустых вершинах;
   - рёбра треугольников идут по линии (красные).

### 6. Плоскость и картограмма с известным ответом (600 м³)
1. Новый чертёж → `KZM_TEST_CARTO`.
2. «+ Поверхность» «Факт» (фактическая) → «Импорт» текстов слоя `KZM_TEST_FACT`, XY «Точка вставки текста».
3. «+ Поверхность» «Проект» (проектная) → «Плоскость…» → «По точке и уклонам»:
   - X = 1000, Y = 2100, отметка 100,50;
   - направление 0, вдоль 10, поперёк 0.
4. **Ожидается:** «наибольший уклон 10,00 ‰, подъём в направлении 0,0°».
5. «В вершинах полилинии…» (флажок «Контур — структурная линия» включён) → голубой прямоугольник слоя `KZM_TEST_BOUND`.
6. **Ожидается:**
   - 4 точки: 100,55 (слева), 100,95 (справа);
   - в «Проект» — линия «Контур плоскости».
7. «+ Картограмма»:
   - факт «Факт», проект «Проект»;
   - «Указать границу…» → тот же прямоугольник;
   - шаг 20.
8. «Показать сетку».
9. **Ожидается:** зелёная временная сетка 3 × 2 квадрата. «Скрыть сетку» убирает её.
10. «Проверить».
11. **Ожидается:**
    - «Насыпь +600 м³, выемка 0 м³; баланс (насыпь − выемка) +600 м³ — недостаток грунта»;
    - «Контрольный расчёт (наложение поверхностей): насыпь 600,0, выемка 0,0 м³;
      расхождение насыпи 0,0 м³ (0,00 %), выемки 0,0 м³»;
    - чертёж не изменился.
12. «Построить».
13. **Ожидается:**
    - в узлах рабочая отметка слева вверху, проектная справа вверху, фактическая справа внизу;
    - под сеткой таблица по рис. 8 с итогом +600.

### 7. Ведомость, ручные сдвиги подписей, пересчёт
1. «Ведомость объёмов…» → укажите точку.
2. **Ожидается:** в строке «Грунт планировки территории» — 600.
3. В ведомости впишите что-нибудь в любую другую строку.
4. Передвиньте одну подпись объёма в квадрате (MOVE).
5. Таблица точек «Проект» → измените отметку правой нижней точки на 101,15.
6. **Ожидается:** картограмма в дереве «УСТАРЕЛА», кнопка «Пересчитать (1)».
7. Нажмите «Пересчитать».
8. **Ожидается:**
   - объёмы изменились;
   - сдвинутая подпись стоит со сдвигом;
   - ведомость на месте, ваша запись цела, «Грунт планировки территории» — новый объём;
   - в командной строке итоги и «Подписей, поставленных на место, сдвинутое вручную: 1».
9. Нажмите `U`.
10. **Ожидается:** отменяется только пересчёт.

### 8. Шаблон подписей и шаблон по умолчанию
1. В картограмме «Подписи в узле»: фактическую — «слева снизу», цвет — красный → «Пересчитать».
2. **Ожидается:** фактические отметки слева внизу, красные.
3. Поставьте фактическую и рабочую в один угол → «Пересчитать».
4. **Ожидается:** «подписи … стоят в одном углу узла» — построение не выполняется.
5. «Сделать шаблоном».
6. Создайте новую картограмму.
7. **Ожидается:** у неё подписи и оформление из шаблона.
8. «Настройки» → «Удалить шаблон» (вернуть как было).

### 9. Выгрузка в Excel
1. Картограмма → «В Excel…» → сохраните `.xlsx`.
2. Откройте файл в Excel.
3. **Ожидается:**
   - листы «Узлы», «Квадраты», «Итоги»;
   - в «Итогах» насыпь по методу квадратов и по контрольному расчёту, расхождение, баланс.
4. Выгрузите то же как `.csv`.
5. **Ожидается:** Excel открывает CSV по столбцам, с запятой в числах.

### 10. Импорт из POINT и блоков
1. Новый чертёж → `KZM_TEST_SOURCES`.
2. «+ Поверхность» «Точки Z» (фактическая).
3. «Импорт» → «POINT (отметка в Z)», «По слоям» `KZM_TEST_Z` → «Проверить».
4. **Ожидается:**
   - будет создано 2 точки (150,25 и 150,00);
   - «POINT с Z = 0 (без отметки) пропущено: 1».
5. «Импортировать».
6. «+ Поверхность» «Блоки» → «Импорт» → «Блоки с атрибутом» → «Указать образец блока» → любой синий кружок с подписями.
7. **Ожидается:**
   - «Атрибут отметки» = `ELEV` (подобран сам);
   - внизу видны значения атрибутов образца.
8. «Атрибут номера» = `NUM` → «Проверить».
9. **Ожидается:**
   - 2 точки: 151,30 (№ 21) и 151,45 (№ 22);
   - блок со значением «152» — «отброшено» (целое число — не отметка).

### 11. Сохранение и другие версии
1. Сохраните DWG, закройте и откройте снова.
2. **Ожидается:**
   - поверхности, структурные линии, исключённые точки (серые), картограмма и её параметры на месте;
   - «Пересчитать» даёт те же объёмы.
3. Повторите шаги 1, 3 и 6 в AutoCAD 2025 или 2026, если они у вас есть.

Сообщите, какие шаги не совпали. Пришлите текст из командной строки и скриншот панели
или чертежа.
