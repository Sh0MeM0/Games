# Проверка версии 0.4.0

## Что проверено автоматически (Linux, без AutoCAD)

- **Сборка.** Шесть сборок (AutoCAD 2021–2026) компилируются без ошибок.
- **103 теста расчётной части**, в том числе:
  - **Т1:** факт 100,00, проект 100,50, квадрат 20×20 → насыпь 200 м³, выемка 0;
  - **Т2:** рабочие отметки −0,98; −0,28; −0,25; −0,35 → выемка 186 м³;
  - **Т3:** +0,50/+0,50/−0,50/−0,50 → насыпь 50, выемка 50; нулевая линия через середины сторон;
  - **Т4:** граница по диагонали квадрата → насыпь 100 м³;
  - **Т5:** «145,32» = «145.32»; MTEXT с форматированием; «12» отбрасывается с причиной;
  - **Т6:** правка одной точки факта меняет только узлы в соседних треугольниках; итоги сходятся.
- **Триангуляция Делоне:**
  - пустая окружность проверена полным перебором на случайных наборах;
  - покрывает выпуклую оболочку;
  - регулярная сетка, вырожденные случаи;
  - 20 000 точек.
- **Расчёт картограммы:** повёрнутая сетка, вогнутая граница (сверка с интегралом), квадрат без данных.
- **Тестовые данные:** числа из пунктов 3 и 6 ниже проверены тестами на тех же координатах.

**Не проверено:** работа в AutoCAD и внешний вид панели. Проверьте по шагам ниже, начиная
с AutoCAD 2022.

## Проверка в AutoCAD

### 1. Установка
1. Запустите `KZM-Setup-0.4.0.exe` при закрытом AutoCAD.
2. Откройте AutoCAD → `KZM`.
3. **Ожидается:** панель с кнопками «+ Поверхность», «+ Картограмма», «Импорт».

### 2. Тестовые данные
`APPLOAD` → `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Kzm.bundle\Examples\kzm-test-data.lsp`.
В модуле две команды:
- `KZM_TEST_DATA` — данные для импорта;
- `KZM_TEST_CARTO` — данные для картограммы.

### 3. Импорт, номера, оформление
1. Новый чертёж → `KZM_TEST_DATA`.
2. «+ Поверхность»: «Факт тест», фактическая → «Создать».
3. «Импорт» → тексты «По слоям» `KZM_TEST_ELEV` → XY «По маркеру» → образец — любая точка POINT
   → «Проверить».
4. **Ожидается:**
   - будет создано 4: три отметки 145,32 и 148,00;
   - строка «12» — «отброшено»: это номер у маркера, при котором нет отметки, поэтому он
     никому не присваивается;
   - спорных 4.

   Номера: у отметки 148,00 — «15» (из текста «t.15 148,00»), у трёх отметок 145,32 — 1, 2, 3
     по порядку.
5. «Импортировать».
6. **Ожидается:** у точек шрифт и высота как у исходных текстов. Подпись точки B («145.32»)
   показывает «145,32» — это Т5 в AutoCAD.
7. Свойства поверхности → «Цвет отметок» → красный → «Применить ко всем точкам».
8. **Ожидается:** отметки стали красными.

### 4. Ручной ввод
1. Свойства поверхности → «Создать вручную…».
2. Укажите точку, введите `150,25`.
3. Укажите вторую точку, нажмите Enter, затем Esc.
4. **Ожидается:**
   - две новые точки с отметкой 150,25 и номерами по порядку;
   - один `U` удаляет обе.

### 5. Триангуляция
1. Свойства поверхности → «Показывать треугольники».
2. **Ожидается:** рёбра на слое `КЗМ_ТРЕУГ`.
3. Переместите точку `MOVE`.
4. **Ожидается:** «Точки изменились… — Обновить треугольники». После обновления треугольники
   соответствуют новому положению точки.

### 6. Картограмма (как Т1)
1. Новый чертёж → `KZM_TEST_CARTO`.
2. Создайте поверхности «Факт» (фактическая) и «Проект» (проектная).
3. Импортируйте в «Факт» тексты слоя `KZM_TEST_FACT`, XY «Точка вставки текста».
4. Импортируйте в «Проект» тексты слоя `KZM_TEST_PROJ`, так же.
5. «+ Картограмма»:
   - факт — «Факт», проект — «Проект»;
   - «Указать границу…» → голубой прямоугольник слоя `KZM_TEST_BOUND`;
   - шаг 20.

   Нажмите «Построить».
6. **Ожидается:**
   - насыпь 400 м³, выемка 0;
   - в узлах +0,50 / 100,50 / 100,00;
   - в квадратах «+…»;
   - под сеткой таблица «Итого, м³ / Насыпь (+) / Выемка (–)» с итогом +400;
   - справа итоги по рядам;
   - в командной строке «Проверка … сходится».
7. Измените отметку любой точки «Проект» в таблице «Точки».
8. **Ожидается:**
   - картограмма в дереве помечена «УСТАРЕЛА»;
   - `KZM_UPDATE` пересчитывает её;
   - объёмы меняются только в соседних квадратах.
9. «Ведомость объёмов…» → укажите точку.
10. **Ожидается:** таблица по форме рис. 9 СТБ 2073-2010, в строке «Грунт планировки территории» —
    400 в столбце насыпи.
11. Нажмите `U`.
12. **Ожидается:** отменяется только последнее действие.

### 7. Сохранение
Сохраните DWG, закройте и откройте снова.
**Ожидается:** поверхности, оформление, картограмма и её параметры на месте; «Пересчитать» даёт
те же объёмы.
