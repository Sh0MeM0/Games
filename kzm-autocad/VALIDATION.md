# Проверка версии 0.6.0

## Что проверено автоматически (Linux, без AutoCAD)

- **Сборка.** Шесть сборок (AutoCAD 2021–2026) компилируются без ошибок.
- **142 теста расчётной части.** Помимо тестов 0.5 (Т1–Т6, структурные линии, плоскости,
  контрольный расчёт, Excel), проверено:
  - **сетка внутри границы:**
    - линии обрезаются по границе, ни одна точка линии не лежит снаружи;
    - на тестовой границе 40 × 20 м — 3 отрезка общей длиной 80 м;
  - **точки пересечения сетки с границей:**
    - найдены все 6;
    - отметки в них интерполируются по поверхностям;
    - пересечение в узле не дублируется;
  - **подписи:** подписываются только узлы внутри границы; наложившаяся подпись отодвигается
    на свободное место с выноской и не выходит за границу;
  - **проекты:**
    - запись и чтение без потерь;
    - данные прежних версий относятся к «Проекту 1»;
    - картограммы 0.5 без изменений не считаются изменёнными по параметрам, но помечаются
      «новое оформление»;
  - **числа шагов 6 и 7 ниже** проверены тестами на тех же координатах: 400 м³; 515,83 м³
    по методу квадратов и 533,33 м³ по контрольному расчёту после правки отметки.

**Не проверено:** работа в AutoCAD и внешний вид. Проверьте по шагам ниже, начиная с AutoCAD 2022.

## Проверка в AutoCAD

### 1. Установка и проект
1. Запустите `KZM-Setup-0.6.0.exe` при закрытом AutoCAD («Исправить / обновить», если стоит 0.5).
2. Откройте новый чертёж → `KZM`.
3. **Ожидается:** вверху панели «Проект: не открыт», ниже — страница «Проекты чертежа».
4. Введите название «Тест» → «Создать».
5. **Ожидается:**
   - вверху «Проект: Тест»;
   - ниже — «Порядок работы».

### 2. Тестовые данные
`APPLOAD` → `C:\Program Files\Autodesk\ApplicationPlugins\Sh0MeM0.Kzm.bundle\Examples\kzm-test-data.lsp`.
Команды:
- `KZM_TEST_DATA` — тексты для импорта;
- `KZM_TEST_CARTO` — данные для картограммы;
- `KZM_TEST_SOURCES` — POINT с отметкой Z и блоки с атрибутами.

### 3. Импорт с подсветкой
1. `KZM_TEST_DATA`.
2. «+ Поверхность»: «Факт тест», фактическая.
3. «Импорт» → «Тексты», «По слоям» `KZM_TEST_ELEV`.
4. **Ожидается:** все 9 текстов сразу подсвечены на чертеже.
5. XY «По маркеру», образец — POINT → «Проверить».
6. **Ожидается:** будет создано 4 точки; «12» — отброшено; спорных 4.
7. «Импортировать».
8. **Ожидается:** подсветка снята; ни один текст не остался выделенным.

### 4. Картограмма с границей по точкам (ответ 400 м³)
1. Новый чертёж → `KZM` → проект «Тест» → `KZM_TEST_CARTO`.
2. «+ Поверхность» «Факт» (фактическая) → «Импорт» текстов слоя `KZM_TEST_FACT`, XY «Точка вставки текста».
3. «+ Поверхность» «Проект» (проектная), точки не нужны.
4. «+ Картограмма»: факт «Факт», проект «Проект».
5. **«Указать границу ▾» → «По точкам — отметки с фактической «Факт»…»:**
   1. Укажите по очереди 4 угла голубого прямоугольника слоя `KZM_TEST_BOUND` (привязка «Конточка»).
   2. На каждый запрос «Отметка … <100,00>» введите `100,50`.
   3. После четвёртой точки нажмите Enter («Замкнуть»).
6. **Ожидается:**
   - на слое `КЗМ_ГРАНИЦА` — замкнутая полилиния;
   - в поверхности «Проект» — 4 точки 100,50 и структурная линия «Граница «…»».
7. «Показать сетку».
8. **Ожидается:** зелёные временные линии только внутри прямоугольника — 2 вертикальные и 1 горизонтальная. «Скрыть сетку» убирает их.
9. «Проверить».
10. **Ожидается:**
    - «Насыпь +400 м³, выемка 0 м³; баланс (насыпь − выемка) +400 м³ — недостаток грунта»;
    - контрольный расчёт — 400,0.
11. «Построить».
12. **Ожидается:**
    - сетка — один зелёный блок, только внутри прямоугольника;
    - отметки — в 2 узлах внутри и в 6 точках, где сетка пересекает границу, за границей ничего;
    - рабочие отметки «+0,50» и объёмы — красные;
    - обозначений 1, 2, 3 / А, Б, В и таблицы справа нет;
    - таблица объёмов — блок ниже сетки с зазором 5 м (10 мм при 1:500), «Всего» +400.

### 5. Блоки и быстрые свойства
1. Щёлкните по сетке.
2. **Ожидается:** выделяется весь блок сетки.
3. Щёлкните по подписи узла.
4. **Ожидается:** в «Быстрых свойствах» (или в «Свойствах», Ctrl+1) видны атрибуты РАБОЧАЯ, ПРОЕКТНАЯ, ФАКТИЧЕСКАЯ.
5. Перенесите таблицу объёмов (MOVE).
6. **Ожидается:** таблица переносится целиком.

### 6. Правка отметки на картограмме (ответ 515,83 и 533,33 м³)
1. У узла (1020; 2120) в «Быстрых свойствах» поставьте ПРОЕКТНАЯ = `101,00`.
2. **Ожидается:** в панели картограмма «УСТАРЕЛА: на картограмме исправлены отметки (1)».
3. «Пересчитать».
4. **Ожидается в командной строке:**
   - «Отметки с картограммы записаны в поверхность «Проект»: 100,50 → 101,00 (изменено точек 0, новых 1)»;
   - насыпь +516 м³ (по столбцам +200, +263, +53);
   - контрольный расчёт 533,3 м³;
   - расхождение насыпи -17,5 м³ (-3,28 %).
5. **Ожидается на чертеже:**
   - в узле рабочая отметка «+1,00»;
   - таблица объёмов осталась там, куда вы её перенесли;
   - в таблице точек «Проект» — новая точка с источником «отметка на картограмме», на чертеже без подписи.

   Число 533,33 проверяется вручную: 400 м³ плоскости + пирамида высотой 0,50 м над 800 м²
   (0,5 × 800 / 3 = 133,33 м³). Метод квадратов меньше, потому что считает по узлам сетки 20 м.
6. Поставьте РАБОЧАЯ = `+0,70` → «Пересчитать».
7. **Ожидается:**
   - замечание «рабочая отметка … всегда Hпр − Hф: правка «+0,70» не принята»;
   - рабочая отметка восстановлена.
8. Нажмите `U`.
9. **Ожидается:** отменяется пересчёт вместе с записью в поверхность.

### 7. Ведомость и удаление
1. «Ведомость объёмов…» → укажите точку.
2. «Удалить картограмму».
3. **Ожидается:** окно со списком: сетка, отметки, объёмы, штриховка, линия нулевых работ, таблица, ведомость (1), граница по точкам; поверхности не меняются.
4. Ответьте «Да».
5. **Ожидается:**
   - всё перечисленное исчезло;
   - точки «Проект» и «Факт» на месте.
6. Нажмите `U`.
7. **Ожидается:** картограмма вернулась.

### 8. Проекты
1. Кнопка «Проект» → «Новый проект…» → «Вариант 2» → «Создать».
2. **Ожидается:** дерево пустое, объекты «Теста» на чертеже видны.
3. «Проект» → «Тест».
4. **Ожидается:** поверхности и картограмма «Теста» снова в панели.
5. «Проект» → «Закрыть проект».
6. **Ожидается:** страница «Проекты чертежа».
7. Сохраните, закройте и откройте DWG.
8. **Ожидается:** проекты на месте.

### 9. Импорт POINT и блоков (как в 0.5)
1. `KZM_TEST_SOURCES` → поверхность → «Импорт» → «POINT (отметка в Z)», по слоям `KZM_TEST_Z` → «Проверить».
2. **Ожидается:** 2 точки (150,25 и 150,00), «POINT с Z = 0 (без отметки) пропущено: 1».
3. «Импорт» → «Блоки с атрибутом» → образец — синий кружок; атрибут номера `NUM` → «Проверить».
4. **Ожидается:**
   - 2 точки: 151,30 (№ 21) и 151,45 (№ 22);
   - «152» — отброшено.

### 10. Старые чертежи и другие версии
1. Откройте чертёж с картограммой 0.5.
2. **Ожидается:**
   - проект «Проект 1» открыт сам;
   - картограмма помечена «Построена прежней версией модуля — нажмите «Пересчитать»…».
3. Нажмите «Пересчитать».
4. **Ожидается:** новое оформление.
5. Повторите шаги 1, 4 и 6 в AutoCAD 2025 или 2026, если они у вас есть.

Сообщите, какие шаги не совпали. Пришлите текст командной строки и скриншот панели или чертежа.
