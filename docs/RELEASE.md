Общий файловый архив: сервер FastAPI/PostgreSQL и Windows-клиент Electron.

В разделе Assets скачайте `SharedArchive-Setup-1.0.0.exe` для Windows 10/11 x64.
Исходники доступны в архивах Source code; инструкция по серверу, первому
администратору и массовому импорту сотрудников находится в README.md.

Установщик не подписан. Установка и удаление на настоящих Windows 10/11,
а также работа с установленными Word/Excel пока не проверены.
Клиентские тесты выполняются перед сборкой в GitHub Actions.
Для надёжного завершения редактирования сохраните и закройте документ,
затем нажмите «Завершить» в клиенте. Автоматическое определение закрытия
Office остаётся необязательной эвристикой.

Для использования клиента необходимо отдельно развернуть сервер с HTTPS;
готового публичного сервера и стандартного пароля администратора нет.
