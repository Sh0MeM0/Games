# Сборка Windows x64

Для выпуска 0.2.0 распространяется только portable-версия. Готовые файлы после сборки
с `--portable-only`:

- `dist/PDFMaster-Portable-x64.zip` — распаковать **весь** архив и запустить `PDFMaster.exe`.
- `dist/PDFMaster-Source.zip` — исходный код, тесты и сценарии сборки приложения.
- `dist/SHA256SUMS.txt` — контрольные суммы portable и исходников.

Обычная сборка без `--portable-only` дополнительно создаёт установщик
`dist/PDFMaster-Setup-x64.exe` и включает его контрольную сумму. При portable-сборке
NSIS не запускается; уже существующий установщик прежней версии в `dist` не
обновляется и не входит в список файлов нового выпуска.

Целевая система — Windows 10/11 x64. Python, Qt, OCR для русского и английского,
модели OCR и конвертер DWG включены. Подключение к сети для конвертации не нужно.
Русский и английский OCR используют официальные модели `tessdata_best`; они
занимают больше места и работают медленнее моделей `fast`, но предпочтительны
для сложных сканов. Модель ориентации `osd` сохранена из `tessdata_fast 4.1.0`.
Версия `best` закреплена коммитом
`e12c65a915945e4c28e237a9b52bc4a8f39a0cec`; URL и SHA-256 каждой модели и её
лицензии находятся в `packaging/windows-assets.lock.json`. Сборка проверяет
их вместе с остальными входящими файлами и копирует полный текст лицензии
Apache 2.0 в `licenses/TesseractBest/LICENSE.txt`.
TIFF, включая многостраничные файлы, обрабатывается этими же компонентами:
дополнительный просмотрщик, драйвер сканера или онлайн-сервис не требуется.
Программа не устанавливает шрифты в Windows; собственные шрифты загружаются
локально. Для отображения переданных DWG на другом компьютере может потребоваться
добавить используемые шрифты в CAD-программу.

`PDFMaster-CLI.exe` запускает тот же Python-модуль в консольном режиме. Файлы с
кириллическими именами передаются через Unicode API Windows. Приложение не
зависит от текущего рабочего каталога. Ошибки старта GUI записываются в
`%LOCALAPPDATA%\PDFMaster\startup.log`.

## Воспроизводимая сборка

Нужны Linux или WSL, Python 3.12+, пакет `zstandard`, GnuPG, GNU make/patch,
Bash и MinGW-w64 (x86_64). Для сборки
установщика также нужен NSIS 3.11+ (с поддержкой `amd64-unicode`). Сборка работает
на Linux без запуска Windows-компилятора Python: готовые официальные Windows
пакеты извлекаются вместе с их лицензиями. Launcher действительно компилируется
в PE x64, установщик создаётся NSIS; архивы не переименовываются в EXE.

```bash
python -m pip install zstandard
python scripts/build_windows.py --portable-only
```

Если инструменты не находятся в `PATH`:

```bash
python scripts/build_windows.py --portable-only \
  --cc /path/to/x86_64-w64-mingw32-gcc \
  --cache /path/to/download-cache
```

Входящие версии, HTTPS URL и контрольные суммы закреплены в
`packaging/windows-assets.lock.json`. Сборка останавливается при несовпадении
SHA-256, не отключает TLS и не требует токенов. Кэш повторно проверяется.
Подпись выпуска LibreDWG проверяется GnuPG с приложенным публичным ключом
сопровождающего проекта; отпечаток — `38A4167B0DB69E49C5F7216CB8C28866AB27A7A2`.
`--stage-only` подготавливает папку portable без ZIP и установщика для проверки
под Windows или Wine. Изменение исходников приложения требует повторной сборки,
загрузки неизменившихся зависимостей повторно не выполняются.

`dxf2dwg.exe` собирается из исходников LibreDWG 0.14 с двумя небольшими
исправлениями для больших DXF: проверка префикса не пересчитывает длину всего
остатка файла, а повторные нулевые ссылки не отключают быстрый поиск ссылок.
Остальные утилиты чтения LibreDWG остаются из официального Windows-архива.
Рецепт и все входящие контрольные суммы находятся в
`scripts/build_libredwg_windows.py` и `packaging/libredwg-patch.lock.json`.
Сборка проверяет подпись исходного архива и применяет точный patch без нечётких
совпадений. Отдельный запуск:

```bash
python scripts/build_libredwg_windows.py --cc x86_64-w64-mingw32-gcc
```

Первая сборка импортера занимает несколько минут. Последующие используют кэш,
сверяя исходники, patch, рецепт, сведения о компиляторе и SHA-256 результата.
Статический импортер зависит только от системных DLL Windows; проверяются его
PE-импорты. Успешная сборка проверена GCC 14 MinGW-w64. Точная конфигурация и
контрольная сумма EXE записываются в `vendor/libredwg/PDFMASTER_BUILD.json`.

Полный исходный архив LibreDWG и его подпись включены в **оба** ZIP в
`assets/licenses/libredwg-0.14.tar.xz` и `.tar.xz.sig`. Полный patch, рецепт,
манифест и GPL также сохранены в portable в `licenses/LibreDWG-PDFMaster`;
готовое расположение для пересборки находится в `PDFMaster-Source.zip`.
Подпись разработчика LibreDWG относится к исходному архиву. Изменённый импортер
собран проектом PDF Мастер и не выдаётся за подписанный оригинальный бинарник.

Перед сборкой дополнительно проверяются SHA-256 добавленных шрифтов и файлов
лицензий по `assets/fonts/SOURCES.json`. Проверка не загружает данные из сети и
также доступна отдельно:

```bash
python scripts/fetch_fonts.py
```

Для восстановления этих файлов из закреплённых Debian-пакетов используйте
`python scripts/fetch_fonts.py --restore`; для распаковки нужен `dpkg-deb`.
Сценарий проверяет контрольные суммы архивов, отдельных шрифтов и лицензий,
сохраняет файлы в репозитории и не устанавливает шрифты в систему.

Portable-версия не требует установки ODA File Converter. DWG создаётся встроенным
GNU LibreDWG; ограничения редакции LibreDWG и восстановления чертежей из PDF/TIFF
описаны в README.
Зависимости и права на распространение перечислены в `THIRD_PARTY_NOTICES.md`.

## Проверка перед распространением

На Windows 10/11 проверьте GUI, русские пути, скан с русским текстом, векторный PDF,
многостраничный TIFF с очисткой и выравниванием, DWG в целевом AutoCAD/совместимом
CAD, DOCX в Word/LibreOffice и запуск portable от обычного пользователя. Проверьте
прерывание длительной конвертации и фактическую читаемость распознанного текста.
Проверка под Wine полезна
для обнаружения отсутствующих DLL, но не заменяет проверку в этих продуктах.
Сборка намеренно не подписывает EXE: сертификат Authenticode издателя не
предоставлен. Контрольные суммы позволяют проверить целостность, но не заменяют
подпись издателя.

Удаление использует точный список поставленных файлов и не удаляет рекурсивно
пользовательские документы, добавленные в каталог программы. При распространении
передавайте также исходники приложения, лицензии и сведения о соответствующих
исходниках зависимостей.
