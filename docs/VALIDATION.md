# Проверки PDF Мастер 0.1.0

Дата: 15 октября 2026 года. Проверки выполнены в Linux x64; Windows-компоненты
дополнительно запускались под Wine 10. Нативного Windows-компьютера, AutoCAD и
Microsoft Word в этой среде нет.

## Автоматические проверки приложения

Результат финального полного запуска: **87 passed**, 0 failed, 0 skipped
(8,18 секунды). Отдельная проверка пакетных имён подтверждает, что два PDF с
одинаковыми именами из разных папок не заменяют результаты друг друга даже при
включённой перезаписи.

Добавлена регрессия OCR для кириллицы в папке языковых данных и в TEMP:
изображение передаётся Tesseract через stdin, папка данных — через Unicode
рабочий каталог и относительное имя. Нативный Tesseract больше не получает
имена файлов с кириллицей через несовместимые строковые аргументы.

Полный набор проверяет извлечение геометрии и текста, повороты страниц, шрифты,
штриховые шаблоны, действительный OCR, редактируемую структуру DOCX, создание
DWG с обратным чтением, пакетную обработку, ошибки, пароль, отмену и GUI.
Нативные LibreDWG и Tesseract доступны: интеграционные проверки не пропускаются.

Команда:

```bash
QT_QPA_PLATFORM=offscreen \
PDF2OFFICE_DXF2DWG=/path/to/libredwg/programs/dxf2dwg \
TESSDATA_PREFIX=/path/to/tessdata \
.venv/bin/python -m pytest -q
```

Векторный DWG проверяется через DWG → DXF и `ezdxf.audit()`: сохранены MTEXT с
кириллицей, LINE, LWPOLYLINE, SPLINE, HATCH, штриховые типы линий и координаты;
ошибок и исправлений аудитора нет. Растровая ссылка также проверена обратным
чтением. Чтение и запись DWG используют одну библиотеку LibreDWG, поэтому эта
проверка не является независимой сертификацией совместимости с AutoCAD.

В DOCX проверены ZIP-пакет, открытие через python-docx, Unicode, свойства текста,
редактируемые VML-фигуры, размеры и поворот страниц, штрихи, изображения и
очистка копии растра под OCR-текстом. Визуальная проверка документа в Microsoft
Word не выполнена.

GUI проверен в offscreen-режиме Qt: создание окна, работа фонового потока,
отмена, частичный успех, отсутствие сохранения пароля, portable-настройки и
доступность элементов в окне 900×700. Снимок экрана: `screenshot.png`.

## Windows-runtime

Под Wine проверены реальные Windows x64 бинарные файлы из дистрибутива:

- Импорт PyMuPDF/MuPDF, ezdxf, python-docx, Pillow, fontTools, NumPy, OpenCV,
  PySide6 QtCore/QtWidgets.
- Запуск встроенного Tesseract 5.5.3 и LibreDWG 0.14.
- `PDFMaster-CLI.exe`: два демонстрационных PDF с русскими именами файлов →
  шесть результатов DWG/DXF/DOCX; код возврата 0, все поля ошибок пусты.
- Обратное чтение Windows-DWG встроенным `dwg2dxf.exe`: у векторного примера
  12 объектов, у скана 30; сигнатура AC1015, 0 ошибок и 0 исправлений аудита.
  Кириллица сохранена в MTEXT. Оба DOCX содержат редактируемый текст.
- Скан: OCR `rus+eng` и приближённая векторизация линий.
- Создание главного окна Qt и корректный русский заголовок.
- Настоящая конвертация через Windows GUI: PDF с русским именем → DOCX,
  работающий фоновый поток, 440 тактов проверки отзывчивости, восстановление
  кнопок после завершения, корректный DOCX размером 37 628 байт. Проверочный
  цикл событий завершился с кодом 0 через `app.exit(0)`.

GUI-сессия в нативной Windows не проверена. Под Wine без дисплея вызов
`app.quit()` зависает даже у минимального `QWidget`, без кода PDF Мастер.
Проверочный сценарий использовал `app.exit(0)`, поэтому штатное закрытие окна
Windows этим тестом не подтверждено. Linux-тесты фоновых задач и завершения
выполняются успешно.

Для Wine потребовалась настройка его локального тестового префикса и UCRT.
Эта настройка относится к Wine; она не включается в инструкции пользователя
Windows. Штатные зависимости приложения входят в дистрибутив.

## Установщик и переносимая сборка

Созданы настоящие PE x64: GUI launcher, консольный launcher и установщик
NSIS 3.11 `amd64-unicode`. В поставку включены автономные Python, Qt, Tesseract
с русскими/английскими данными OCR и LibreDWG. Архивы зависимостей сверены с
закреплёнными SHA-256; подписи исходников и Windows-архива LibreDWG проверены
GnuPG с опубликованным ключом сопровождающего проекта.

Реальный установщик запущен под Wine в тихом режиме:

- Установка в каталог с кириллицей и пробелами завершилась с кодом 0.
- Установленная `PDFMaster-CLI.exe doctor` завершилась с кодом 0 и обнаружила
  требуемые модули и встроенные конвертеры.
- После установки в путь с кириллицей и пробелами проверена конвертация
  векторного PDF и скана в четыре DWG/DOCX с OCR `rus+eng`; переменная `TEMP`
  также указывала на каталог с кириллицей и пробелами. Код возврата 0,
  сигнатуры DWG и целостность DOCX корректны. Передача PNG через stdin и
  относительный путь `--tessdata-dir .` устранили ошибку кодировки Tesseract.
- Маркер `portable.flag` удалён установщиком: установленная версия использует
  обычные настройки текущего пользователя.
- Настоящий `Uninstall.exe /S` удалил приложение, runtime и запись удаления
  из HKCU; завершение проверено после фонового этапа NSIS.
- Добавленный пользователем файл в каталоге установки сохранился с прежним
  содержимым. Удаление не использует рекурсивное стирание всего каталога.

Это проверка Windows-бинарников под Wine, а не проверка установки на отдельном
компьютере Windows 10/11. Полная распаковка portable обязательна: один launcher
без соседних `runtime`, `app`, `assets` и `vendor` не является всей программой.

## Что ещё требует проверки в целевых программах

- Открытие, сохранение и редактирование DWG в конкретной версии AutoCAD/аналога.
- Визуальное расположение, переносы строк и редактирование фигур в Microsoft Word.
- Сложные производственные чертежи, большой объём страниц, нестандартные шрифты,
  низкокачественные сканы и фотографии с перспективой.
- Правильность размеров, OCR-цифр, обозначений и соответствие оформления ГОСТ.

EXE не подписаны сертификатом Authenticode. SHA256SUMS.txt проверяет целостность
файлов. Примеры и автоматические проверки подтверждают реализованный сценарий,
но не гарантируют точность преобразования произвольного PDF.
