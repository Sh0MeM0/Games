# Проверка проекта

Проверено в облачной Linux-среде 09.10.2026:

- Python 3.12: 15 серверных тестов на настоящем PostgreSQL прошли. Проверены хэширование, лимит входов, ротация/отзыв токенов, роли, блокировка пользователя, атомарный импорт, конкурирующий checkout, истёкшая аренда, конфликт сохранений, история, откат, корзина и ограничения файлов.
- Node.js 24: 8 клиентских тестов прошли. Проверены HTTPS-адрес, параллельное обновление токенов, потеря сети, локальные пути, отправка сохранения перед освобождением блокировки, отказ после потери аренды и восстановление копий после перезапуска.
- TypeScript и production-сборка Vite прошли; Ruff, shell syntax и `git diff --check` прошли.
- PostgreSQL/FastAPI/Caddy запущены через Docker Compose. Проверка `/health` и функциональный сценарий выполнены через настоящий HTTPS с проверкой конкретного тестового CA, без отключения TLS.
- HTTPS-сценарий: вход администратора, CSV с 30 пользователями, загрузка OOXML-документа, блокировка, сохранение, скачивание, откат, удаление папки, восстановление и отзыв доступа после выхода прошли.
- Интерфейс проверен в Chromium с IPC-мостом проверки и настоящим API: вход, список документов, создание папки, пользователи, журнал; ошибок JavaScript не было. Это проверка renderer, она не заменяет запуск установленного Electron на Windows.
- CLI: создание администратора через скрытый ввод пароля и импорт CSV через stdin прошли.
- Бэкап создан и контрольные суммы проверены. Восстановление выполнено в отдельном тестовом окружении: файл совпал побайтно, пользователи сохранились, изменения после снимка исчезли.
- Основной Caddyfile успешно прошёл `caddy adapt --validate`.
- Скрипты `cloud-setup.sh` и `cloud-start.sh` выполнены; повторная установка зафиксированных зависимостей и повторный запуск сервисов прошли.
- `electron-builder` успешно создал `client/release/SharedArchive-Setup-1.0.0.exe` (около 148 МБ, настоящий NSIS PE-файл, код завершения 0). Установщик содержит Windows x64 приложение, использует русский пользовательский NSIS-сценарий и создаёт деинсталлятор во время установки. Подпись издателя не добавлена. SHA-256: `5d6c046a938cb532d6bbe5c2903346121af25c400473e934bbb1e6b65f759505`.

Не выполнялись: установка/удаление на настоящих Windows 10/11, интеграция с установленными Word/Excel, публичное развёртывание VPS и получение Let's Encrypt для пользовательского домена. Эти шаги требуют Windows/Office и реального домена; см. [чек-лист Windows](WINDOWS-CHECKLIST.md) и [README](../README.md).

Автоматическое определение закрытия Office не гарантируется: основной путь — сохранить/закрыть документ и нажать «Завершить». Дополнительная проверка файлового дескриптора Windows — отключённая по умолчанию эвристика.

Настройки облачной среды `install_script` и `start_skill` сохранены в черновике. Это не публикация и не проверка восстановления в новой облачной задаче. Для активации нужно проверить и сохранить настройки среды, затем опубликовать её.
